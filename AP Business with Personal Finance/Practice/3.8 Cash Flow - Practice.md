# 3.8 Cash Flow Statement — 练习册（会写 · 会看）

> 配套课件：[[3.8 The Cash Flow Statement - Slides]]　·　同组练习：[[3.6 Income Statement - Practice]] · [[3.7 Balance Sheet - Practice]]
> **目标：** 分清 inflow / outflow（A），排出一张现金流量表并让它接到 balance sheet 的现金行（B），解释"有利润却没现金"（C、E），能在三张表之间指路（D）。
> ⚠️ 本节只考 **inflow / outflow** 两栏，不考 operating / investing / financing 三分法——那不在本课程范围内。

### C1. 这三件事会让现金流变化吗？

**Meadow Lane Florist** 10 月。本月 **net income = $18,000**，但老板发现账上现金从 **$22,000** 掉到 **$5,300**。

本月现金记录：

| 项目 | 金额 |
|---|---|
| Payments received from customers | $96,000 |
| Sold an old display fridge | $800 |
| Payments to flower growers | $43,000 |
| Wages paid to staff | $30,000 |
| Rent paid | $5,000 |
| Interest paid | $1,200 |
| Taxes paid | $6,300 |
| Bought a delivery van | $18,000 |
| Repaid loan principal | $6,000 |
| Owner drawings | $4,000 |

其他资料：本月 revenue $104,000（其中 $8,000 客户尚未付款）· inventory 增加 $2,000 · accounts payable 增加 $1,000 · 折旧 $1,500

(a) 编出 10 月的现金流量表（流入 / 流出 / net change / 期末现金）。（5 分）

## 📝 答案与判分（教师用 · 学生版到此为止）

### 0. 热身

earned → **inflow**；paid → **outflow**；selling → **inflow**；buying → **outflow**；taking → **inflow**；repaying → **outflow**。
折旧：**它不涉及现金流动**（钱在买设备那天就付了），所以只在 income statement 上以费用出现。

### A. 分类

| # | 判断 | 理由 |
|---|---|---|
| 1 | Inflow | 顾客付现 |
| 2 | Inflow | **上月的收入，本月的现金** |
| 3 | Inflow | 课件把 interest **earned** 列为流入 |
| 4 | Inflow | 卖资产是流入（对应"buying"是流出） |
| 5 | Inflow | 借款是流入（对应"repaying"是流出） |
| 6 | Inflow | equity infusion |
| 7 | Outflow | 付供应商 |
| 8 | Outflow | 付员工 |
| 9 | Outflow | 付租金 |
| 10 | Outflow | 付利息 |
| 11 | Outflow | 付税 |
| 12 | Outflow | 买资产花钱 |
| 13 | Outflow | 还本金 |
| 14 | Outflow | drawings / dividends |
| 15 | **Not a cash flow** | 赊销：收入已确认，现金 30 天后才到 |
| 16 | **Not a cash flow** | 折旧是非现金费用 |

### B. Harbour Lane Bakery

| Inflows | | Outflows | |
|---|---|---|---|
| Cash sales | 48,000 | Suppliers | 24,000 |
| Collection from café | 14,000 | Wages | 15,000 |
| Sale of mixer | 1,500 | Rent | 6,000 |
| New bank loan | 20,000 | Interest paid | 500 |
| | | Taxes paid | 2,500 |
| | | Oven | 9,000 |
| | | Loan principal | 4,000 |
| | | Owner drawings | 6,000 |
| **Total inflows** | **83,500** | **Total outflows** | **67,000** |

**Net change = +$16,500**　→ 期末现金 = 8,000 + 16,500 = **$24,500**
④ 必须等于 balance sheet 上 **Cash 一行**（同一日期）——两张表如果不等，说明有一笔现金没记。

### C1. 会动现金吗

| # | 判断 | 出现在哪张表 |
|---|---|---|
| 1 | does not move cash（本月） | IS 记 revenue；现金下月到 → 现金表不出现 |
| 2 | does not move cash | 只出现在 IS（非现金费用） |
| 3 | **moves cash（inflow）** | 现金表 inflow；同时 BS 上记 unearned revenue（负债） |
| 4 | moves cash（outflow） | 现金表 outflow；**不进 IS** |
| 5 | moves cash（outflow） | 现金表 outflow；**也进 IS**（利息费用） |
| 6 | moves cash（outflow） | 现金表 outflow；资产互换 → IS 只记折旧 |

### C2. 三个原因

| 原因 | 机制 | 本店例子 |
|---|---|---|
| 赊销 | 收入今天确认，现金 30/45/60 天后才到 | $5,000 婚礼订单，30 天后付款 |
| 大额资产购置 | 现金流出，但 IS 只记折旧 | 买烤箱 $9,000 |
| 偿还贷款本金 | 现金流出，但**本金不是费用** | 还本金 $4,000 |

补充：**利息是费用（进 IS），本金不是（只进现金表）**——这一条解释相当大一部分利润-现金差。本店：利息 500 vs 本金 4,000，比例 1:8。

### C3. 连线

A → ③（再融资）　B → ①（加快收款）　C → ②（争取账期）　D → ④（重谈还款）

### D1. 哪个问题问哪张表

| # | 问题 | 表 |
|---|---|---|
| 1 | 赚了多少利润 | **IS** |
| 2 | 12/31 账上现金 | **BS** |
| 3 | 现金净增/净减 | **CF** |
| 4 | working capital | **BS** |
| 5 | 利润收回多少现金 | **CF**（与 IS 对照看） |
| 6 | net worth | **BS** |
| 7 | 毛利率变化 | **IS**（+ percent change） |
| 8 | 设备投入的现金 | **CF** |

### D2. 负现金流不一定坏

1. **可接受（要盯紧）**——扩张期把现金变成库存与设备，属于 3.8.B.2 里"资产购置"型；关键是看订单能否变现。
2. **可接受**——还本金造成的流出换来了更低的利息，是改善。
3. **危险**——现金 900 对 12,000 工资，就是"profitable but insolvent"的现实版，必须立刻 ①③④ 三招并用。
4. **危险**——+5,000 全靠借款撑，收入跌 30%，是"借新还旧"的早期信号。

### D3. 对不上账

(a) **必须相等**（同一日期）：现金流量表的期末现金 = balance sheet 的 Cash。
(b) 三种可能：① 有一笔现金收付没进现金表（如 owner drawings 3,000）；② 现金表把某笔 inflow/outflow 记反或重复；③ balance sheet 的 cash 未更新（例如银行手续费 3,000 只在银行对账单上）。
(c) **不能**——报表内部不一致就是重大不确定性；银行会要求先做 bank reconciliation（对账）再交。

### E. Meadow Lane Florist（判分点）

(a)

| Inflows | | Outflows | |
|---|---|---|---|
| Payments from customers | 96,000 | Flower growers | 43,000 |
| Sale of old fridge | 800 | Wages | 30,000 |
| | | Rent | 5,000 |
| | | Interest paid | 1,200 |
| | | Taxes paid | 6,300 |
| | | Delivery van | 18,000 |
| | | Loan principal | 6,000 |
| | | Owner drawings | 4,000 |
| **Total** | **96,800** | **Total** | **113,500** |

**Net change = −$16,700**（96,800 − 113,500）→ 期末现金 = 22,000 − 16,700 = **$5,300** ✓

(b) 利润 18,000 → 现金变化 −16,700，差 **34,700**，三类原因：

| 类别 | 本月的具体金额 | 对差额的方向 |
|---|---|---|
| 赊销 / 营运资金 | AR +8,000（未收回）、inventory +2,000、AP +1,000 → 净 −9,000；折旧 +1,500 → 合计 **−7,500** | 现金少于利润 |
| 资产购置 | 买 van −18,000（卖旧冰箱 +800）→ **−17,200** | 现金少于利润 |
| 贷款本金 + 分红 | 本金 −6,000、drawings −4,000 → **−10,000** | 现金少于利润 |

验算：18,000 − 7,500 − 17,200 − 10,000 = **−16,700** ✓（其中 18,000 + 6,000 + 4,000 = 28,000 是"非费用但要付现金"的那一块，和课件 3.8.B.2 一致）

(c) 参考答案："Two numbers: **net change in cash −$16,700** with only **$5,300** left, against the **$18,000 van and $6,000 principal** that caused it — the shop is profitable but its cash cushion is nearly gone, so the first question is how fast the $8,000 receivable will come in."
判分：(a) 5 分（分类正确 2 + 合计正确 2 + 期末现金 1）；(b) 4 分（三类原因各 1 + 金额对得上 1）；(c) 3 分（引两个数字 2 + 说明机制 1）。

## 🔗 三表联动（讲完本节回头串一次）

| 你看到的 | 在另一张表上的位置 |
|---|---|
| IS 的 net profit | → BS 的 **retained earnings** |
| BS 的 **Cash** 行 | = 现金表的**期末现金** |
| 现金表里"买设备"的流出 | → BS 的 long-term assets 增加（IS 只记折旧） |
| 现金表里"还本金" | → BS 的 liabilities 减少（**IS 完全不记**） |
| BS 的 AR 增加 | → 解释"利润没变成现金"（现金表与 IS 的差额） |

> 一句话收尾：**IS 讲"赚没赚"，BS 讲"有什么"，CF 讲"钱去哪了"——三张表对不上，就是有一笔业务记错了。**

### 常见错误清单（板书用）

1. 把 interest **earned** 说成 outflow、interest **paid** 说成 inflow（读动词）
2. 把折旧写进现金表（非现金）
3. 把赊销当流入（本月没收到钱）
4. 把"还本金"当费用放进 IS
5. 忘了 dividends / drawings 是流出
6. 期末现金不与 balance sheet 对账就给结论
