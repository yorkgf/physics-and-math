## 三份练习共同的骨架

| 部分 | 训练什么 | 为什么必须有 |
|---|---|---|
| **0 热身** | 口头、5 分钟 | 上课前 5 分钟把术语叫醒，不占纸 |
| **A 认项** | 分类判断 | 会计题 80% 的分丢在"放错行"，不是算错数 |
| **B 编表** | 手写一遍 | 只有自己排过一次，才知道小计从哪来 |
| **C 读数** | margin / working capital / 现金诊断 | AP 简答题的问法就在这里 |
| **D 查错** | 看别人的错表 | 反向练习，比正向做三遍有效 |
| **E 综合** | AP 式情境题（带分值） | 直接当小测用 |
