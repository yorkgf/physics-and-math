## 📝 答案与判分（教师用 · 学生版到此为止）

### 0. 热身

1. **Assets = Liabilities + Owners' equity**（fundamental accounting equation）
2. **一年**
3. **既不是资产也不是负债**——contra-asset，冲减长期资产
4. **负债**（unearned revenue）
5. **Assets − Liabilities**

### A. 分类

| # | 答案 | 备注 |
|---|---|---|
| 1 | Current asset | |
| 2 | Current asset | AR |
| 3 | Current asset | inventory |
| 4 | Current asset | prepaid expense |
| 5 | Long-term asset | fixed asset |
| 6 | Long-term asset | |
| 7 | **Contra-asset**（减长期资产） | 最常错 |
| 8 | Intangible asset | patent |
| 9 | Current liability | AP |
| 10 | Current liability | accrued operating expense |
| 11 | Current liability | unearned revenue |
| 12 | Current liability | 同一笔贷款的**当期部分**要拆出来 |
| 13 | Long-term liability | |
| 14 | Owners' equity | |
| 15 | Owners' equity | retained earnings |

### B1. 资产负债表

| Current assets | | Long-term assets | |
|---|---|---|---|
| Cash | 18,000 | Equipment 60,000 − 18,000 | 42,000 |
| Accounts receivable | 9,500 | Van 24,000 − 6,000 | 18,000 |
| Inventory | 12,000 | Patent（intangible） | 8,000 |
| Prepaid rent | 3,000 | | |
| **Total current** | **42,500** | **Total long-term** | **68,000** |

**Total assets = $110,500**

| Current liabilities | | Long-term liabilities | |
|---|---|---|---|
| Accounts payable | 11,000 | Bank loan | 30,000 |
| Wages payable | 4,500 | | |
| Unearned revenue | 2,000 | | |
| Current portion of loan | 6,000 | | |
| **Total current** | **23,500** | **Total L-T** | **30,000** |

**Total liabilities = $53,500**　Owners' equity = 48,000 + 9,000 = **$57,000**
验：53,500 + 57,000 = **110,500** ✓
**Working capital = 42,500 − 23,500 = $19,000**（正的、宽裕）

### B2. Okafor household

(a) Assets 15,200 + 38,000 + 310,000 + 17,500 + 21,000 = **$401,700**；Liabilities 4,300 + 8,700 + 232,000 + 19,000 = **$264,000** → **Net worth $137,700**
(b) 卖车：assets −17,500（车）+12,000（现金）= −5,500 → 396,200；用现金还贷：cash −8,700、负债 −8,700 → assets 387,500、liabilities 255,300 → **Net worth $132,200**。
少了 **5,500**＝卖价低于账面价值的**折旧实现**——net worth 只认真实价值，不认账面原价。

### B3. 交易分析

| # | 交易 | 动的两行 | A | L | E |
|---|---|---|---|---|---|
| — | 起点 | — | 110,500 | 53,500 | 57,000 |
| 1 | 赊购零件 3,000 | Inventory +3,000 / AP +3,000 | 113,500 | 56,500 | 57,000 |
| 2 | 还供应商 2,000 | Cash −2,000 / AP −2,000 | 111,500 | 54,500 | 57,000 |
| 3 | 老板投入 5,000 | Cash +5,000 / Capital +5,000 | 116,500 | 54,500 | 62,000 |
| 4 | 收到欠款 1,500 | Cash +1,500 / AR −1,500 | 116,500 | 54,500 | 62,000 |
| 5 | 新贷款 10,000 | Cash +10,000 / LT loan +10,000 | 126,500 | 64,500 | 62,000 |
| 6 | 现金买设备 6,000 | Cash −6,000 / Equipment +6,000 | 126,500 | 64,500 | 62,000 |
| 7 | 老板提取 4,000 | Cash −4,000 / Equity −4,000 | 122,500 | 64,500 | 58,000 |

- **没改变 A 总额：** 第 4、6 笔——都是**资产内部互换**（cash ↔ AR、cash ↔ equipment）。
- **改变 net worth：** 第 3、7 笔（owner 投入/提取）；另有 **当期净利润**（进 retained earnings，同时使资产或减少负债）——这就是 3.6 与 3.7 的接口。

### C1. 与对手比

(a) Cedar：42,500 − 23,500 = **+19,000**（够）。BikeHub：30,000 − 34,000 = **−4,000**（不够，current liabilities 超过 current assets）。
(b) Cedar 53,500/110,500 = **48.4%**；BikeHub 88,000/128,000 = **68.8%**。
(c) **BikeHub**：working capital 为负 = 短期偿债有缺口，负债率又高 20 个点，一旦供应商收紧账期就可能撑不住（3.7.B.3 的 bankruptcy 情境）。

### C2. Point in time / period

1. I　2. B　3. B（retained earnings 是时点数）　4. I　5. B

### C3. 预付的保养卡

(a) **Current liability — unearned revenue $2,000**。
(b) **不算 revenue**（服务还没交付）。
(c) 明年 3 月：负债 −2,000、**收入 +2,000** → net profit 上升、equity 上升（或先形成 AR → 收现）。

### C4. 现金买设备 10,000

| 项目 | 结果 |
|---|---|
| Total assets | **不变**（cash −10,000、equipment +10,000） |
| Total liabilities | 不变 |
| Net worth | 不变 |
| Working capital | **−10,000**（现金是 current asset，设备是 long-term） |

> 一句话：**没变穷，但变"紧"了**——这正是 3.8 要接着讲的现金问题。

### D1. Ridgeway 的四处错误

| 行 | 错在哪 | 正确做法 | 改正后的变化 |
|---|---|---|---|
| Accumulated depreciation | 被列为负债 | **contra-asset**，从 Instruments 减掉 | Assets 58,000 → **49,000**（−9,000）；负债同时 −9,000 |
| AR（18 个月后到期） | 归到 current | **long-term asset** | 总额不变，working capital ↓ 12,000 |
| Unearned tuition 15,000 | 预收记成了收入/权益 | **current liability** | 负债 +15,000；equity −15,000（−9,000 → **−24,000**） |
| Bank loan 50,000 全部 long-term | 当期部分没拆 | **10,000 current + 40,000 long-term** | working capital ↓ 10,000；总额不变 |

改正后：**A 49,000 = L 73,000 + E (−24,000)** ✓
① net worth = **−$24,000**。
② **negative net worth**：assets 不足以覆盖 liabilities，lender 眼里就是没有 cushion；若无法取得足够的 current assets 支撑运营，下一步是 **bankruptcy**（legal process：liquidate / reorganize）。

> 讲评要点：这张表**配平了**（58,000 = 67,000 − 9,000），但三处分类错叠加正好互相抵消——**配平 ≠ 正确**。这也是本节最值钱的一句话。

### D2. 配不平

答案 **2**：供应商发票 $6,000 收到但没入账 → liabilities 应为 47,000，A 86,000 = L 47,000 + E 39,000 ✓
（1 会让 assets 更高、差得更多；3 会让 assets 变成 80,000、仍不平；4 会让两边都变；5 会使两边同时下降，差额不变。）

### E. Cedar & Co.（判分点）

(a) 第 1 年 WC = 40,000 − 21,000 = **$19,000**；第 2 年 WC = 42,500 − 23,500 = **$19,000** → **一分没变**。
Net worth：第 1 年 **$47,000**；第 2 年 **$57,000**（+10,000）。
(b) 因为增长**压在存货上**：inventory 从 7,000 涨到 12,000（+5,000），cash 从 22,000 跌到 18,000（−4,000）——current assets 只涨 2,500，而 current liabilities 涨 2,500，正好抵掉。数字：**+5,000 inventory / −4,000 cash**。
(c) 参考答案："I would ask why inventory rose 71% (7,000 → 12,000) while revenue growth is unknown, and how much of that inventory is slow-moving. Working capital is flat at 19,000 and cash fell 4,000, so the extra assets are sitting on the shelf, not in the bank; if the parts are obsolete, both working capital and net worth would fall."
判分：(a) 3 分（两年 WC + net worth + "没变"的结论）；(b) 3 分（必须引两个数字）；(c) 4 分（追问数字 + 说明机制）。

### 常见错误清单（板书用）

1. Accumulated depreciation 当负债 / 当资产（它是 contra-asset）
2. 预收款当收入、当资产
3. 一笔贷款不拆 current portion
4. working capital 用 total assets 去减（必须 current 对 current）
5. 交易只改一行 → 等式不平
6. net worth 报 gross assets（lender 要的是 assets − liabilities）
