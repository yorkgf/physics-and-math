### 🔴 高频错题 TOP 5

#### 1. Q3: 类型转换 (double casting) — 6人错 (75%)
**正确答案: A | 错误分布: C(4人), B(1人), D(1人)**

```
Which evaluates to 3.5?
A: (double) 2 / 4 + 3     → 2.0/4 + 3 = 0.5 + 3 = 3.5 ✅
B: (double) 2 / (4 + 3)   → 2.0/7 = 0.285... ❌
C: (double) (2 / 4) + 3   → (double)(0) + 3 = 3.0 ❌
D: (double) (2 / 4 + 3)   → (double)(3) = 3.0 ❌
```

**核心陷阱：** `2 / 4` 先算整数除法得 `0`，再转double就是 `0.0`。
**关键规则：** `(double)` 只作用于紧挨着的那个值，不是整个括号！

**全班注意：**
> `(double) (2 / 4)` vs `(double) 2 / 4` 结果完全不同！

## 📝 类型转换专题（全班必会）

**Q3 详解：**

```java
// 选项C: (double) (2 / 4) + 3
//         ↑ 先算括号内: 2/4 = 0 (整数除法!)
//         ↑ (double)(0) = 0.0
//         ↑ 0.0 + 3 = 3.0 ❌

// 选项A: (double) 2 / 4 + 3
//         ↑ (double)2 = 2.0
//         ↑ 2.0 / 4 = 0.5 (double除法!)
//         ↑ 0.5 + 3 = 3.5 ✅
```

**黄金法则：**
> 1. `(double)` 只作用于**紧邻的下一个值**
> 2. 括号内的整数运算**先算完再转型**
> 3. 只要有一个操作数是double，整个表达式就是double运算

**练习题（全班做）：**
```java
(double) 5 / 2       // = ?
(double) (5 / 2)     // = ?
5 / (double) 2       // = ?
(int) 7.8 + 2        // = ?
(int) (7.8 + 2)      // = ?
```

**答案：** 2.5, 2.0, 2.5, 9, 9
