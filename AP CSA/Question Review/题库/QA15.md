# QA15: Modify ArrayList with reviseList

## Question
reviseList replaces odd elements with element+1. Input [1,2,3,3,2,1]. Result?

## Answer Key
**C** — [2,2,4,4,2,2]

1→2(奇), 2→2(偶), 3→4(奇), 3→4(奇), 2→2(偶), 1→2(奇)。set(i, temp+1)原地替换。
