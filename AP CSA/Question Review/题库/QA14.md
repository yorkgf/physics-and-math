# QA14: maxHelper — Fix the Method

## Question
How to fix maxHelper so it works correctly?

## Answer Key
**B** — Insert before Line 1: `if (numVals == 1) return nums[0];`

numVals=1时直接返回nums[0]作为base case。必须在Line1(递归调用)之前，否则numVals=1时仍会调用maxHelper(0)。
