# QA08: GPA and Majors — Correct Data Sets

## Question
University wants major with highest avg GPA among graduating students. Which 2 data sets to combine?

## Answer Key
**B** — Data sets 1 and 4

Dataset 1: student ID + major + graduation year
Dataset 4: student ID + final GPA
通过student ID关联，可以按专业计算平均GPA。
