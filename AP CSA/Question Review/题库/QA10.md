# QA10: Exclamation Points in 2D Array

## Question
int[][] arr = {{6,2,5,7},{7,6,1,2}}. Print '!' when arr[j][k] > j+k. How many times?

## Answer Key
**C** — 6次

第0行: (0+0)=0,6>0✓; (0+1)=1,2>1✓; (0+2)=2,5>2✓; (0+3)=3,7>3✓ → 4次
第1行: (1+0)=1,7>1✓; (1+1)=2,6>2✓; (1+2)=3,1>3✗; (1+3)=4,2>4✗ → 2次
共6次
