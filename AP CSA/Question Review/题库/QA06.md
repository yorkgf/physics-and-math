# QA06: Scan Usernames from Text File

## Question
File has "Cohen-Isabel\nLee-Cindy\n...". Goal: ["ICohen","CLee","APatel","MSanchez"]. Which code works?

## Answer Key
**C** — `String[] temp = scan.next().split("-"); usernames.add(temp[1].substring(0,1) + temp[0]);`

split("-")将每行分为[姓, 名]，取名字首字母+姓。
