# QA02: Bird Constructor Causing Compilation Error

## Question
Bird class has constructor `Bird(String str, String col, boolean cf)`. Which new constructor causes compilation error?

## Answer Key
**D** — `public Bird(String col, String str, boolean cf)` has same type signature (String, String, boolean) as existing constructor — duplicate signature causes compile error.

## Key Concepts
- 构造函数重载(overloading)基于参数类型列表
- 参数名不影响签名，类型顺序才是关键
- 相同参数类型顺序 = 编译错误
