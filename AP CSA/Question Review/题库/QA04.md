# QA04: Shirt Class — Attributes vs Behaviors

## Question
Shirt class has color and size variables. poloShirt is declared as Shirt. Which description is accurate?

## Answer Key
**A** — The color and size variables are **attributes** of the poloShirt object.

变量(instance variables)是对象的属性(attributes)，方法是对象的行为(behaviors)。
