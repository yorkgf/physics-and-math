# QA01: Variable Declarations for Sensor Program

## Question
A program needs to maintain: whether sensor is active (boolean), number of items detected (int), and average time per detection (double).

## Answer Key
**D** — `boolean active; int items; double avgTime;`

bool用于真/假状态，int用于整数计数，double用于小数时间值。
