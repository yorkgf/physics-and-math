# QA22: 2D Array Declaration for 'test1234'

## Question
Print "test"+nums[0][0]+nums[1][0]+nums[1][1]+nums[0][1] = "test1234". Which declaration?

## Answer Key
**D** — `int[][] nums = {{1,4},{2,3}}`

nums[0][0]=1, nums[1][0]=2, nums[1][1]=3, nums[0][1]=4
验证: test+1+2+3+4 = test1234 ✓

## Key Concepts
- 2D数组: 第一索引=行，第二索引=列
- int[][] nums = {{行0列0,行0列1},{行1列0,行1列1}}
- 注意nums[0][1]是第0行第1列(不是第1行)
