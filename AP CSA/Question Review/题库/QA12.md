# QA12: Initial Value of Shortest

## Question
Find shortest string length in array. What initial value for `shortest` variable?

## Answer Key
**A** — `Integer.MAX_VALUE`

设为最大整数，确保第一个字符串长度一定小于它，从而正确初始化最短值。

## Key Concepts
- Integer.MAX_VALUE = 2,147,483,647
- 初始值策略: 找最小用MAX，找最大用MIN
- 若初始化为0，所有字符串长度≥0，结果永远是0
