# QA18: removeDups — Fix for Adjacent Duplicates

## Question
removeDups removes adjacent duplicates but skips some. How to fix?

## Answer Key
**D** — Add `else` before `k++`

删除元素后，下一个元素移到索引k，不应该再k++。只有在**没有**删除时才递增k。

## Key Concepts
- ArrayList.remove()后索引自动前移
- 删除后不应增加索引(否则跳过相邻重复)
- else k++: 只在未删除时前进
