# QA23: mystery Binary Search — What Does It Return

## Question
mystery is a binary search on sorted array arr with no duplicates. What does mystery(0, arr.length-1, num) return?

## Answer Key
**A** — The number of elements in arr that are **less than** num.

当num不在arr中时，返回low(插入位置=小于num的元素数)。当num在arr中时，返回其索引(也等于小于num的元素数，因为数组有序无重复)。
