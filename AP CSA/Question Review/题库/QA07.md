# QA07: Hop Count in Nested Loops

## Question
Outer loop: num=0,2,4,6,8 (5 times). Inner loop: val=0,1,2,3,4 (5 times). How many times is 'hop' printed?

## Answer Key
**C** — 25次

外循环执行5次(0,2,4,6,8)，每次外循环内循环执行5次(0,1,2,3,4)。5×5=25。

## Key Concepts
- 嵌套循环次数 = 外循环次数 × 内循环次数
- 外循环: num+=2, 0到<10, 执行5次
- 内循环: val++, 0到<5, 执行5次
