# QA11: Last Arrays Merged in Merge Sort

## Question
int[] vals = {80,50,30,20,60,70}. Which arrays are merged last in mergeSortHelper?

## Answer Key
**D** — {30,50,80} and {20,60,70} merged to {20,30,50,60,70,80}

递归分解: {80,50,30}和{20,60,70} → 各自递归排序 → 最后合并{30,50,80}和{20,60,70}。

## Key Concepts
- merge在两个递归调用之后执行(post-order)
- 最后的merge是最顶层的合并
