# QA24: recur Method — Base-3 Conversion

## Question
recur(val): dig=val%3; if val/3>0 return dig+recur(val/3); return dig. What prints for recur(32)?

## Answer Key
**D** — 2101

32%3=2, 32/3=10→dig="2"+recur(10)
10%3=1, 10/3=3→"1"+recur(3)
3%3=0, 3/3=1→"0"+recur(1)
1%3=1, 1/3=0→"1"(停止)
组合: "2"+"1"+"0"+"1" = "2101"
