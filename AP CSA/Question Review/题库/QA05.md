# QA05: Substrings of LMNOP

## Question
String str1 = "LMNOP"; str2 = str1.substring(3); str2 += str1.substring(2,3); What is str2?

## Answer Key
**A** — "OPN"

`substring(3)` → 从索引3开始: "OP"
`substring(2,3)` → 索引2到2: "N"
合并: "OP"+"N" = "OPN"

## Key Concepts
- substring(start) — 从start到末尾
- substring(start, end) — 从start到end-1 (不含end)
- LMNOP的索引: L=0,M=1,N=2,O=3,P=4
