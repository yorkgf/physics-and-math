# QA17: Values Printed in Array Traversal

## Question
int[] arr={3,1,0,4,2}. Loop prints arr[j]+j. What is printed?

## Answer Key
**B** — 3 2 2 7 6

arr[0]+0=3, arr[1]+1=2, arr[2]+2=2, arr[3]+3=7, arr[4]+4=6

## Key Concepts
- arr[j]+j: 数组值加索引值
- 注意不是arr[arr[j]]
- 逐一代入: 3+0=3, 1+1=2, 0+2=2, 4+3=7, 2+4=6
