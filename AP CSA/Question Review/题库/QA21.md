# QA21: recur Method — Fibonacci-like Recursion

## Question
recur(n): if n≤1 return 1; else return recur(n-2)+recur(n-1). What is recur(4)?

## Answer Key
**C** — 5

recur(0)=1, recur(1)=1
recur(2)=recur(0)+recur(1)=2
recur(3)=recur(1)+recur(2)=3
recur(4)=recur(2)+recur(3)=2+3=5
