# QA16: Values Printed by Recursive mystery(10,0)

## Question
mystery(j,k): if j>k, call mystery(j-2,k+2); then print j. What prints for mystery(10,0)?

## Answer Key
**D** — 4 6 8 10

调用链: mystery(10,0)→mystery(8,2)→mystery(6,4)→mystery(4,6)[j≤k停止递归]
展开时按顺序打印: 4,6,8,10(先打印最深层的j值)

## Key Concepts
- 递归调用后的语句在递归返回后执行
- print在递归调用之后 → 打印顺序是递归展开顺序
- 类似栈: 最后调用的最先打印
