# QA13: maxHelper — When Does It Not Work

## Question
maxHelper recursively finds max in first numVals elements. When does it NOT work?

## Answer Key
**D** — Method maxHelper **never** works as intended.

没有基本情况(base case)! numVals=1时仍调用maxHelper(0)，maxHelper(0)调用maxHelper(-1)...无限递归，永远Stack Overflow。

## Key Concepts
- 递归必须有base case(终止条件)
- 无base case → 无限递归 → StackOverflowError
- 此方法对任何输入都不能正常工作
