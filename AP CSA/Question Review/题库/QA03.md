# QA03: Random Value in Range [0.5, 5.5)

## Question
Math.random() returns [0,1). Which expression gives uniform distribution over 0.5 ≤ r < 5.5?

## Answer Key
**D** — `r = d * 5.0 + 0.5`

d∈[0,1) → d*5.0∈[0,5) → d*5.0+0.5∈[0.5, 5.5)。公式：`d * (max-min) + min`。
