# QA09: findNext Method Condition

## Question
findNext returns first index of val in arr after position start. What while condition is correct?

## Answer Key
**A** — `(pos < arr.length) && (arr[pos] != val)`

必须先检查pos<arr.length防止越界，&&保证短路求值(short-circuit)。
