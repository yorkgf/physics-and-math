# 🧮 多元微积分 × 线性代数（结合式学习路径）

> **这门课要拿到的东西**：不是「学完两门课」，而是把一条主线走通 ——
> **微分的本质是线性映射**：$df_p$ 是一个线性映射，它的矩阵是 Jacobian，它的行列式是换元时的体积元，它的对称版本是 Hessian；而积分的终极形式（Stokes）就是「外微分 + 行列式」。
>
> **判据（能说出来就算接通了）**：
> 1. 看到 Jacobian → 能在脑中写出矩阵、画出列向量张成的平行体
> 2. 看到 Hessian → 会问「它对称吗？正定吗？」并知道极值第二判别法就是二次型判号
> 3. 看到换元积分 → 能答「这是哪个线性映射的行列式」
> 4. 看到 $\nabla\times$ / $\nabla\cdot$ → 能写成矩阵与一次/二次外积
> 5. 看到散度定理 + 斯托克斯 → 知道它们是同一个 $\int_{\partial\Omega}\omega=\int_\Omega d\omega$ 的特例
> 6. 能用新语言重写自己的 [[电磁学/麦克斯韦方程组]] 与 [[电磁学/拉梅系数]] 笔记
