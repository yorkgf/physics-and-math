# 🧱 线性代数（从 0 开始）

> **起点确认**：没系统学过线代。已有的是**代数运算 + 向量/点积/叉积/$2\times2,3\times3$ 行列式 + 到 Stewart Ch13 的微积分 + 物理里的张量直觉**。
> 所以「从 0 开始」指的是**结构理论从零**，不是算术从零 —— 这条路线可以快过计算，把时间砸在 L1（会看）和 L2（会拆）。

> **终点画像（能说出这六句就算学到位）**
> 1. 一个矩阵不是数表，是**线性映射在基下的坐标**；换基就是 $P^{-1}AP$
> 2. 解 $A\mathbf x=\mathbf b$ = 问「$\mathbf b$ 在不在 $A$ 的列空间里」；解集的结构由零空间维数决定
> 3. **秩-零化度定理**是"未知数个数 − 独立方程个数 = 自由度"的严格版
> 4. 实对称矩阵可以**正交对角化**，特征值全实 —— 这是二次型、极值判别、简正模式的地基
> 5. 行列式 = 线性映射把单位平行体放大的**有向倍数**（唯一满足多线性+反对称+归一的函数）
> 6. 投影/最小二乘 = 把向量拆成「列空间 + 列空间的正交补」

## 🗺️ 四阶段路线

### ⬜ L0 · 会算（约 20 h / 3–4 周）

**目标**：把四种操作练成**不需要思考的肌肉记忆** —— 后面所有抽象概念都会被计算错误拖死。

- [ ] 3b1b ELA **ep1–ep5**（向量、张成空间、线性变换与矩阵、矩阵乘法=复合、行列式）
- [ ] Hefferon **§1.1–1.6**（高斯消元、行阶梯形、解集、矩阵乘法、逆、初等矩阵）
- [ ] Hefferon **§2.1–2.5**（行列式的计算与性质、余子式展开）
- [ ] 18.06SC **L1–L4** + Problem Set 1–2
- [ ] **每天 10 min drill**（下面「💪 计算 drill」表），错一次记一次

> 🚦 **出口自测**（全部闭卷、限时）：$4\times4$ 行列式 2 题全对；$3\times3$ 逆矩阵 3 题全对；一个含参数的 $Ax=b$ 判出「无解/唯一解/无穷解」的临界值；能说出**三种初等行变换各自的矩阵形式**，并解释「为什么行变换不改变解集」。
> ❌ **不许提前**：如果消元还会算错，不要进 L1 —— 抽象阶段会把你已知的东西全部搅浑。

### ⬜ L1 · 会看：$\mathbb R^n$ 与线性映射（约 35 h / 5–6 周）★ 真正的转折点

**目标**：从「解方程组的技巧」切换到「研究一个映射」。这一阶段是**多元微积分能不能接通的关键**，因为 $df_p$ 就是一个线性映射。

- [ ] **向量空间 / 子空间 / 张成 / 线性无关 / 基 / 维数**（Hefferon §3.1–3.3）
- [ ] **四个基本子空间**：列空间、零空间、行空间、左零空间 + 秩（Strang 18.06SC L5–L11，这是他的招牌）
- [ ] **秩-零化度定理**及其证明（自己推一遍，不许抄）
- [ ] **线性映射的矩阵表示**、核与像、同构 $V\cong\mathbb R^n$（Hefferon §3.2–3.5）
- [ ] **换基与相似** $P^{-1}AP$（最容易「以为懂」的一节，必须做题）
- [ ] 3b1b ELA **ep6–ep9、ep12**（逆矩阵、列空间与零空间、点积与对偶、change of basis）
- [ ] 建笔记目录 `数学/线性代数/`，每个概念写**三栏卡**（见下方 🔄 学习法）

> 🚦 **出口自测**：
> - 不查书证明 $\operatorname{rank}(AB)\le\min\{\operatorname{rank}A,\operatorname{rank}B\}$
> - 口述「秩为 2 的 $4\times5$ 矩阵」的四幅画面：列空间是 $\mathbb R^4$ 中的平面、零空间是 $\mathbb R^5$ 中的 3 维子空间、$Ax=b$ 有解当且仅当 $b\perp$ 左零空间、解集（若非空）是 3 维仿射子空间
> - 用**零空间 ⟂ 行空间**重做 [[矢量分析/平面方程与法向量的几何直觉]]，并解释两个平面交线方向为什么是法向量叉积

### ⬜ L2 · 会拆：特征值 · 内积 · 对称 · 正定（约 45 h / 6–8 周）★ 与多元微积分在此合流

**目标**：拿到物理和多元微积分真正在用的那批工具。这一阶段结束，[[学习进度/多元微积分与线性代数]] 的判据 1–3 应全部达成。

| 块 | 内容 | 直接用途 |
| --- | --- | --- |
| 2a | 特征值/特征向量、特征多项式、对角化、Cayley–Hamilton、最小多项式 | 18.03 线性 ODE 组与矩阵指数 $e^{At}$；[[学习进度/经典力学\|耦合振子的简正模式]] |
| 2b | 内积空间、Gram–Schmidt、正交补、$A^{\mathsf T}$ 与伴随、投影 | 最小二乘拟合实验数据；傅里叶/分离变量的抽象框架 → [[电磁学/泊松方程与拉普拉斯方程]] |
| 2c | **谱定理**（实对称可正交对角化）、同时对角化 | Hessian 判极值 → Stewart §14.7；惯量张量主轴 |
| 2d | **二次型与正定性**、Sylvester 判据、合同变换 | 多元极值第二判别法、能量稳定性、$\nabla^2$ 的符号 |
| 2e | SVD、条件数、伪逆（可延到 L4） | 数据拟合的病态问题；主成分分析 |

- [ ] Hefferon §4.1–§4.3 + §5（特征值、内积）· 或 Friedberg/Insel/Spence Ch5–Ch6（更严谨）
- [ ] 18.06SC L17–L22 + Exam 1、2（做真题，OCW 有答案）
- [ ] 3b1b ELA **ep13–ep16**（叉积重看、特征值与特征向量、AB=λA、总结）
- [ ] 用 Python/numpy 验证谱定理（AP CSA 的编程能力直接变现，见 🧪 项目）

> 🚦 **出口自测**：给出 Stewart §14.7 极值第二判别法的**完整证明**（$H$ 对称 → 正交对角化 → $h^{\mathsf T}Hh=\sum\lambda_iy_i^2$ → 全正为极小）；解一个二自由度耦合振子并求简正频率；解释换元积分里 $|\det J|$ 为什么是体积缩放率 → 接 [[电磁学/拉梅系数]]。

### ⬜ L3 · 会抽象：对偶 · 商 · 外代数（约 30 h，选做但强烈建议）

**目标**：为微分形式买门票。到这一步，行列式从「一个算法」变成「$\bigwedge^n$ 的作用」，$\nabla\times$ 从「一个魔性公式」变成「$1$-形式的 $d$」。

- [ ] 对偶空间与对偶映射（$A^{\mathsf T}$ 的真正身份）
- [ ] 商空间、不变子空间、特征分解的结构版
- [ ] 双线性型/二次型的坐标无关表述
- [ ] **多重线性代数与外积**：$\bigwedge^k$、行列式的公理化、Hodge 星
- [ ] 第二遍教材：**Axler《Linear Algebra Done Right》**（不用行列式的谱理论，薄而漂亮）或免费同级替代 **Treil《Linear Algebra Done Wrong》**
- [ ] **Winitzki《Linear Algebra via Exterior Products》**（免费，专走「外积 = 行列式 = 体积元」）
- [ ] 问题书自查：**Halmos《Linear Algebra Problem Book》**

> 🚦 **出口自测**：不查资料写出「$\bigwedge^2$ 在 $\mathbb R^3$ 上就是叉积」（对照自己已有的 [[矢量分析/叉乘与行列式关系详解]]），并推出 $\det(AB)=\det A\det B$ 是「两个有向体积缩放率的复合」这一句话的证明。
> ✅ 通过后 → 直接开 [[学习进度/多元微积分与线性代数]] 阶段 4（Bachman 微分形式）。

### ⬜ L4 · 会用（长期，与物理/CS 并行）

- [ ] **MIT 18.065 Linear Algebra for Data Analysis / ML (Strang)** —— 把 L2 的工具砸进真实数据
- [ ] 最小二乘与测量平差：把 [[电磁学/亥姆霍兹线圈法测量永磁铁的磁矩]] 这类实验数据做一次正规拟合
- [ ] 数值视角：条件数、迭代法、为什么「对称正定」在算法里是贵宾

## ❗ 易错点预警（先把坑标出来）

| 坑 | 症状 | 解药 |
| --- | --- | --- |
| 把矩阵当数表 | 只会算，不会解释 | 每步都问「这是哪个映射」 |
| 混淆相似与合同 | $P^{-1}AP$ 与 $P^{\mathsf T}AP$ 随手写 | 相似=同一映射换基；合同=同一二次型换基 |
| 特征值 ≠ 奇异值 | 以为任何矩阵都能正交对角化 | 只有正规/对称矩阵可以；一般矩阵要 SVD |
| 「线性无关」口头会背不会用 | 判 $S^1,S^2,S^3$ 相关性卡住 | 一律回到「$c_1v_1+\dots=0$ 只有零解」硬算 |
| 行列式余子式展开乱用 | 算 $4\times4$ 做到吐血 | 先化上三角，或挑最多 0 的那一列 |
| 计算错当概念错 | 判断"不懂"其实是笔误 | drill 表 + 错题表，两栏分开统计 |
