## 🧭 使用流程（每次学习）

1. 打开对应科目 `进度.md`
2. 看「下次起点」→ 直接开始，不用回想
3. 学完更新：**本讲完成情况 → 下次起点 → 新增待办练习**
4. 有卡点/易忘点 → 记到总览的「易忘点速记」
5. 周末填「每周回顾」，更新顶部总表的进度与状态

## 📅 每日打卡格式（2026-09-26 起启用）

> 用法：每天学完发一句中文即可（例：“今天做了 14.6 奇数题 5 道错 1，线代 Hefferon §1.1 看完”）。
> 我会**同时**更新：① 科目文件的分单元清单勾选 ② 「✍️ 练习进度」表状态 ③ 顶部「📌 续学锚点」的“下次动作” ④ 本页顶部总表与入口行 ⑤ 日志。**不需要你自己改表格。**

每条记录会留下四个信息，以便下次找到位置：

| 字段 | 作用 |
| --- | --- |
| 🎬 **视频** | 看到第几集（带直达链接）、下一集号与时长 |
| ✍️ **练习** | 做到哪一题、错哪几道、下次从哪道接继 |
| 🧱 **线代** | L0–L3 当前位置 + 当日 drill 做没做 |
| 📘 **正文** | Stewart 章节位置（防止视频腿虚假超前） |
