# 📚 学习进度总览

> 用途：并行自学多门课程时，一处看清「每科进行到哪、上次学到哪、下一步做什么」。
> 用法：**每次学习结束立刻更新对应科目的 `进度.md`**，然后回来刷一遍下方的总表。
> 相关：[[学习进度/学习记录模板]] · [[任务管理器/今日任务]]

## 🎯 当前并行课程一览

> 下表由 Dataview 自动生成（读取每科文件 frontmatter 的 `状态`/`progress`/`total`）。改科目文件即可自动更新。

```dataview
TABLE WITHOUT ID
  file.link AS 科目,
  状态 AS 状态,
  progress + "/" + total AS 进度,
  上次学到 AS 上次学到,
  下次起点 AS 下次起点
FROM "学习进度"
WHERE 科目
SORT file.name ASC
```

## 🧭 使用流程（每次学习）

1. 打开对应科目 `进度.md`
2. 看「下次起点」→ 直接开始，不用回想
3. 学完更新：**本讲完成情况 → 下次起点 → 新增待办练习**
4. 有卡点/易忘点 → 记到总览的「易忘点速记」
5. 周末填「每周回顾」，更新顶部总表的进度与状态
