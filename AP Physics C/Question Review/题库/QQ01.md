## Analysis

This question tests understanding of the difference between static and kinetic friction coefficients.

### Common Mistakes
- **Answer E**: Likely confused static friction maximum (μ_s N) with kinetic friction formula
- Many students chose E, suggesting difficulty distinguishing when to use μ_s vs μ_k

### Key Concepts
- **Static friction** ($f_s$): $0 \leq f_s \leq \mu_s N$ (variable, up to maximum)
- **Kinetic friction** ($f_k$): $f_k = \mu_k N$ (constant)
- Typically: $\mu_s > \mu_k$
