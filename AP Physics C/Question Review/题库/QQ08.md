# Q08 - Equation of motion for pulley modified atwood

## Question Topic
改进型滑轮运动方程 (Modified Atwood Motion)

## Original Question
Two blocks are joined by a light string that passes over the pulley shown above, which has radius R and moment of inertia I about its center. T1 and T2 are the tensions in the string on either side of the pulley and α is the angular acceleration of the pulley. Which of the following equations best describes the pulley's rotational motion during the time the blocks accelerate?
(A) m2gR = Iα
(B) (T1 + T2)R = Iα
(C) T2R = Iα
(D) (T2 - T1)R = Iα
(E) (m2 - m1)gR = Iα

## Answer Key
**Correct Answer: C**

## Analysis

This question continues the modified Atwood theme from Q02, requiring free-body analysis and equation of motion.

### Free-Body Analysis Process
1. Draw FBD for each mass
2. Identify all forces on each mass
3. Apply Newton's Second Law: $\sum F = ma$
4. For connected masses: same acceleration magnitude

### Modified Atwood Machine Elements
- Two or more masses
- Rope over pulley (possibly massless, frictionless)
- May include inclined planes, additional pulleys
- Constraint: rope length constant → accelerations related

### Key to Success
- Correctly identifying all forces
- Consistent coordinate system selection
- Proper sign conventions
