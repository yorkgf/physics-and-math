# Final Q20 - Velocity as function of time

## Original Question
An object with mass $m$ is attached to a horizontal ideal spring with spring constant $k$. The object is initially at rest at equilibrium where the position $x = 0$. The object is pulled to the right until the spring is stretched to $x = A$. It is released and allowed to slide across a surface with negligible friction. At time $t = 0$, the object is at equilibrium and moving to the left.
Which of the following is a correct expression for the velocity $v$ of the object as a function of $t$?
(A) $v(t) = -A\sqrt{\frac{k}{m}}\cos\left(\sqrt{\frac{k}{m}}t\right)$
(B) $v(t) = A\sqrt{\frac{k}{m}}\cos\left(\sqrt{\frac{k}{m}}t\right)$
(C) $v(t) = -A\sqrt{\frac{k}{m}}\sin\left(\sqrt{\frac{k}{m}}t\right)$
(D) $v(t) = A\sqrt{\frac{k}{m}}\sin\left(\sqrt{\frac{k}{m}}t\right)$
(E) $v(t) = -A\sqrt{\frac{m}{k}}\cos\left(\sqrt{\frac{m}{k}}t\right)$

## Answer Key: D

**Explanation:**
The timer is started when the spring is unstretched and the object is moving to the left so the position is given by: $x(t) = -A\sin\omega t$, where $\omega = \sqrt{\frac{k}{m}}$. So, $v(t) = -A\omega\cos\omega t = -A\sqrt{\frac{k}{m}}\cos\left(\sqrt{\frac{k}{m}}t\right)$.
