# Final Q10 - Vertical distance between falling objects

## Original Question
An airplane travels horizontally at a constant velocity $\vec{v}$. An object is dropped from the plane, and one second later another object is dropped from the plane. If air resistance is negligible, what happens to the vertical distance between the two objects while they are both falling?
(A) It increases.
(B) It decreases.
(C) It remains the same.
(D) It depends on the mass of the objects.
(E) It depends on the horizontal speed of the plane.

## Answer Key: C

### Key Concepts
- Same acceleration $g$ for all objects
- If released together: distance between them stays constant
- If released at different times: $d = \frac{1}{2}g(2t\Delta t - \Delta t^2)$

### Common Mistakes
- Forgot same $g$ means same rate of fall
- Didn't consider release time difference
