## Analysis

This problem connects weight, gravitational force, and escape velocity.

### Escape Velocity Formula
$$v_{escape} = \sqrt{\frac{2GM}{R}}$$

Or using weight:
$$W = mg = \frac{GMm}{R^2} \Rightarrow g = \frac{GM}{R^2}$$
$$v_{escape} = \sqrt{2gR}$$

### Weight on Surface
$$W = mg$$

### Why 50% Correct Rate?
- Requires connecting weight to surface gravity
- Need to correctly derive escape velocity from given information
- Many students used wrong relationship between W, g, and v_escape

### Key Relationship
If weight W is given on planet surface:
$$g_{planet} = \frac{W}{m}$$
$$v_{escape} = \sqrt{2g_{planet}R} = \sqrt{\frac{2WR}{m}}$$
