### Key Concepts
- Same acceleration $g$ for all objects
- If released together: distance between them stays constant
- If released at different times: $d = \frac{1}{2}g(2t\Delta t - \Delta t^2)$

### Common Mistakes
- Forgot same $g$ means same rate of fall
- Didn't consider release time difference
