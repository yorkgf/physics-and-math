### Key Concepts
- $L = I\omega = constant$ (no external torque)
- $K = \frac{1}{2}I\omega^2 = \frac{L^2}{2I}$
- When $I$ decreases → $\omega$ increases, $K$ increases

### Classic Mistake
- Thinking $K$ stays the same (confusing with $L$)
- Actually $K$ increases because work is done pulling arms in
