### Key Concepts
- $\vec{v}_{cm} = \frac{m_1\vec{v}_1 + m_2\vec{v}_2}{m_1 + m_2}$
- Total momentum conserved if no external forces
- If at rest initially: $m_1\vec{v}_1 + m_2\vec{v}_2 = 0$

### Common Mistakes
- Calculated relative velocity instead of CM velocity
- Used scalar instead of vector
