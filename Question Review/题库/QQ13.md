## Analysis

This is a basic friction force calculation problem.

### Friction Force Formula
$$f = \mu N$$

### When to Use Static vs Kinetic?
- If object is NOT sliding: Use static friction (up to maximum)
- If object IS sliding: Use kinetic friction

### Common Approach
1. Find normal force N
2. Calculate maximum static friction: $f_{s,max} = \mu_s N$
3. Compare required force to $f_{s,max}$
4. If required > $f_{s,max}$: use kinetic friction
5. If required ≤ $f_{s,max}$: use static friction (equal to applied force)
