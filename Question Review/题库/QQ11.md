### Conservation of Momentum in 2D
For an explosion with no external forces:
$$\vec{p}_{initial} = \vec{p}_{final}$$
$$0 = m_1\vec{v}_1 + m_2\vec{v}_2 + ...$$

This means: **Total momentum vector must be zero**

### Breaking Into Components
$$p_{x,initial} = p_{x,final}$$
$$p_{y,initial} = p_{y,final}$$

### Why No One Got It Right?
- This type of problem requires careful vector component analysis
- Students may not have recognized that initial momentum is zero
- Vector addition in 2D can be tricky
- The answer choices may have subtle differences

### Key Insight
In an explosion with system initially at rest:
- Total momentum BEFORE = 0
- Total momentum AFTER = 0 (vector sum of all fragments)
