### Friction Force on Sliding Objects
$$f_k = \mu_k N$$

For cars on a surface:
- Normal force N typically equals weight (on level ground)
- Kinetic friction coefficient $\mu_k$ is usually less than static $\mu_s$

### Typical Mistake Patterns
- **Answer A/E**: Confused which friction coefficient to use
- Forgetting that kinetic friction is constant during sliding
- Incorrectly applying $\mu_s$ when motion is occurring

### Key Principle
Once an object is sliding, kinetic friction applies:
$$f_k = \mu_k N$$ (constant magnitude)

Static friction applies only when objects are not sliding relative to each other.
