## Course Description

AP Computer Science Principles introduces students to the breadth of the field of computer science. Students will learn to design and evaluate solutions and to apply computer science to solve problems through the development of algorithms and programs. They will incorporate abstraction into programs and use data to discover new knowledge. Students will also explain how computing innovations and computing systems—including the Internet—work, explore their potential impacts, and contribute to a computing culture that is collaborative and ethical.

This course is designed to be the equivalent of an introductory, college-level breadth course in computer science. Students will use **Python** as the primary programming language throughout the course. A minimum of **9 hours** of dedicated class time is reserved for the Create Performance Task.

---

## Course Objectives

Upon completion of this course, students will be able to:

1. **Design computational solutions** — Investigate a problem, design an approach, and evaluate solution options
2. **Develop algorithms and programs** — Implement algorithms and write programs in Python to solve real-world problems
3. **Apply abstraction** — Develop programs using lists and procedures that manage complexity through abstraction
4. **Analyze and test programs** — Explain code behavior, determine results, and identify and correct errors
5. **Investigate computing innovations** — Explain how computing systems and networks work and evaluate their impacts
6. **Contribute to responsible computing** — Practice safe, ethical, collaborative, and inclusive computing

### **Create Performance Task (CPT) — Dedicated Class Time**
**Timeline:** April 6 – April 25, 2027 (≥ 9 hours dedicated in-class time)

> **Three weeks dedicated to CPT development with no competing instruction.** Students develop a program of their own design that solves a problem or creates an experience of personal interest.

| Phase | Dates | In-Class Hours | Focus | Deliverables |
|-------|-------|----------------|-------|--------------|
| | Apr 5 | — | **🌸 Qingming Festival** | |
| **Planning & Design** | Apr 6–9 | 3–4 hours | Finalize project topic, write design plan, begin coding environment setup | Project proposal approved, pseudocode/flowchart, initial file structure |
| **Development** | Apr 10–16 | 5–6 hours | Implement program with list and procedure abstractions, iterative testing and debugging | Working program with all required elements (list + procedure with parameter) |
| **Finalization** | Apr 17–21 | 2–3 hours | Record video (≤ 1 min), capture Personalized Project Reference screenshots, begin submitting to AP Digital Portfolio | Program PDF, video, PPR ready for submission; students encouraged to submit by Apr 21 |
| **Final Submission Window** | Apr 22–25 | Office hours support | Final checks, troubleshooting submission issues, late submissions | All students must submit by Apr 25 to allow buffer before deadline |

> **College Board CPT Submission Deadline: April 30, 2027 (11:59 PM ET)** — All three components must be submitted as final to AP Digital Portfolio. **Class target: submit by April 25** to allow troubleshooting time.

#### CPT Requirements (College Board)
- **Program:** A functioning program of the student's design; must include at least one list and at least one student-developed procedure with a parameter
- **Video:** ≤ 1 minute, shows the program running and producing output; no narration or subtitles required
- **Personalized Project Reference (PPR):** Screen captures of (1) list code, (2) list being used, (3) procedure definition, (4) procedure call — **no comments or course content in captures**
- **Written Responses (on exam day):** WR1 Program Design/Function/Purpose; WR2(a) Algorithm Development; WR2(b) Errors and Testing; WR2(c) Data and Procedural Abstraction

> **Academic Integrity:** Students may use generative AI as a learning aid but must understand and be able to explain all code. Any code not written by the student must be acknowledged with a comment. Collaboration is permitted only during ideation and program development — not on the video or PPR.

## Course Policies

### Attendance
- Regular attendance is essential; computing concepts build sequentially
- Students are responsible for obtaining materials and completing assignments when absent
- More than 3 unexcused absences may result in grade deductions

### Late Work
- Assignments submitted late will receive a 10% deduction per day
- Assignments more than 3 days late will receive a maximum of 50%
- Exceptions made for excused absences and emergencies

### Academic Integrity
- All work must be your own
- Collaboration is encouraged during labs and CPT development, but individual submissions must be original
- Plagiarism or unauthorized AI code submission on graded work will result in a zero and possible course failure
- AI tools (ChatGPT, GitHub Copilot, etc.) may be used as learning aids outside of assessments, but you must understand and be able to explain all code you submit

### Create Performance Task Integrity
- CPT code, video, and PPR must be your own independent work (except where collaborative development is explicitly allowed)
- All code not written by you must be attributed with a comment
- Submitting work from AP Central samples or practice tasks is not permitted
- Video and PPR must be completed individually

### Professional Conduct
- Respect all classmates, especially during collaborative activities and presentations
- Ethical use of data, respect for privacy, and responsible computing are emphasized throughout the course
- Constructive peer feedback is expected and graded
