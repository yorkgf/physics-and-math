# AP CSP Create Performance Task 个人项目完整检查清单

> **官方文档版本**：Fall 2023
> **项目权重**：AP成绩重要组成部分
> **建议完成时间**：至少9小时课堂时间

---

## 📋 三大提交组件总览

| 组件 | 是否可合作 | 格式 | 核心要求 |
|------|-----------|------|---------|
| **A: 程序代码** | ✅ 可合作 | PDF | 完整代码 + 注释 |
| **B: 演示视频** | ❌ 独立完成 | 视频 | ≤1分钟, ≤30MB |
| **C: 项目参考** | ❌ 独立完成 | 代码截图×4 | 无注释 |

---

## 📦 Component A: 程序代码提交检查清单

### 文件格式要求
- [ ] 所有代码在**一个PDF文件**中
- [ ] 代码包含适当注释（注明合作者或引用来源）
- [ ] 字体至少 **10pt**
- [ ] 截图清晰、不模糊
- [ ] 代码中注明所有引用来源

### 代码功能必选要求

#### ✅ 输入 (Input)
至少包含一种输入方式：
- [ ] 用户交互（按钮点击、表单输入等）
- [ ] 设备触发事件
- [ ] 在线数据流读取
- [ ] 文件读取

#### ✅ 数据抽象 (List/Collection)
- [ ] 使用至少一个 **List**（列表/数组）存储数据
- [ ] 列表存储多个相关数据项
- [ ] 列表帮助管理程序复杂度
- [ ] 不使用列表会导致代码需要大量重复修改

#### ✅ 学生开发的过程 (Procedure)
- [ ] 有明确的过程名称
- [ ] 有返回类型（如需要）
- [ ] 有**一个或多个参数**
- [ ] 参数在过程内部被使用
- [ ] 过程实现了程序的核心目的
- [ ] ❗ **内置函数、事件处理器、main方法不算学生开发**

#### ✅ 算法三要素（过程内部必须包含）
- [ ] **顺序 (Sequencing)**：代码按顺序执行
- [ ] **选择 (Selection)**：包含 `if` / 条件判断语句
- [ ] **迭代 (Iteration)**：包含循环（`for` / `while`）

#### ✅ 过程调用
- [ ] 在程序的其他地方调用了你开发的过程

#### ✅ 输出 (Output)
- [ ] 基于输入产生输出
- [ ] 输出形式：视觉、文本、听觉或触觉
- [ ] 输出与程序功能相关

---

## 🎥 Component B: 演示视频检查清单

### 内容要求
- [ ] 完整展示程序运行过程
- [ ] 清晰展示**输入**过程
- [ ] 展示至少一个**核心功能**
- [ ] 展示程序产生的**输出**结果

### 技术规格
- [ ] 格式：`.webm`, `.mp4`, `.wmv`, `.avi`, 或 `.mov`
- [ ] 时长：**不超过1分钟**
- [ ] 文件大小：**不超过30MB**

### ❌ 视频中绝对禁止
- [ ] 你的姓名、学号、头像等个人识别信息
- [ ] 语音叙述（文字字幕可以）

## 📸 Component C: 个人项目参考检查清单
### ⚠️ 此部分错误会导致书面回答得0分！

### 所有截图通用要求
- [ ] ❗ **截图不包含任何注释**（有注释→书面回答部分得0分）
- [ ] 截图前删除代码中的所有注释
- [ ] 字体至少 **10pt**（推荐12pt）
- [ ] 截图清晰不模糊
- [ ] 不包含课程内容或老师的注释
- [ ] 原始尺寸截图（不要缩小后再放大）

### 代码片段 1: 过程定义
- [ ] 完整展示学生开发的过程
- [ ] 显示过程名称
- [ ] 显示返回类型（如适用）
- [ ] 显示一个或多个参数
- [ ] 参数在过程中被使用
- [ ] 算法同时包含：顺序 + 选择 + 迭代

### 代码片段 2: 过程调用
- [ ] 展示在程序中何处调用了上述过程

### 代码片段 3: 列表数据存储
- [ ] 展示数据如何被存储到列表中

### 代码片段 4: 列表数据使用
- [ ] 展示列表中的数据如何被访问
- [ ] 或展示如何从列表数据创建新数据
- [ ] 展示列表如何帮助实现程序目的

### 特殊情况处理
- [ ] 代码过长时：分成最多3张截图
- [ ] 代码过宽时：换行或旋转90度（所有图片旋转方向一致）

## 🚨 学术诚信与AI使用检查清单

### ✅ AI 工具使用规范（允许使用，但必须）
- [ ] 理解每一行代码的功能
- [ ] 能够在考试中详细解释代码逻辑
- [ ] AI仅用于辅助理解和调试
- [ ] 注明AI生成的代码

### 📚 代码引用规范
根据代码来源添加相应注释：

| 代码来源 | 必须添加的注释 |
|---------|---------------|
| 老师提供的起始代码 | `This code was provided as starter code by my teacher.` |
| API/开源代码 | `This code was made freely available by [source].` |
| AI生成的代码 | `This code was generated using [AI Tool Name].` |
| 与合作者共同编写 | 在注释中说明合作部分 |

### ❌ 绝对禁止行为
- [ ] 抄袭未注明来源的代码
- [ ] 在视频或Component C制作中合作
- [ ] 提交后修改代码
- [ ] 使用AP官方样例代码作为自己的提交

| 阶段 | 时间分配 | 核心任务 |
|------|---------|---------|
| 1 | 第1-2小时 | 头脑风暴项目想法，技术可行性验证 |
| 2 | 第3-5小时 | 编写核心代码，实现列表和过程 |
| 3 | 第6小时 | 测试调试，确保所有功能正常 |
| 4 | 第7小时 | 录制演示视频 |
| 5 | 第8小时 | 准备Component C的4个代码截图 |
| 6 | 第9小时 | 对照此清单检查所有项目，提交 |

## ⚠️ 错误后果速查表

| 错误 | 后果 |
|------|------|
| Component C截图包含注释 | **书面回答部分得0分** |

| 代码中缺少列表 | 数据抽象部分失分 |

## 💡 项目建议选题方向

1. **工具类**：待办事项管理器、学习闪卡、计算器
2. **游戏类**：简单的文字冒险、猜数字、记忆游戏
3. **数据处理类**：成绩分析器、预算管理、数据可视化
4. **创意类**：生成器（名言、密码、故事）、画板
