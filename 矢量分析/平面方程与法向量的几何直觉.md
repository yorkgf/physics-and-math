# 平面方程与法向量的几何直觉

## 1. 核心结论：方程系数即法向量

在三维空间中，平面的标准代数方程（一般方程）为：
$$Ax + By + Cz = D$$

这个方程有一个非常核心的性质：**变量 $x, y, z$ 的系数 $A, B, C$ 直接构成了垂直于该平面的法向量（Normal Vector）** $\mathbf{n}$：
$$\mathbf{n} = \langle A, B, C \rangle$$

**示例**：对于平面 $x + y + z = 1$，隐藏的系数均为 $1$。即 $1x + 1y + 1z = 1$，因此该平面的法向量就是 $\mathbf{n} = \langle 1, 1, 1 \rangle$。

---

## 2. 为什么系数刚好是法向量？（点积推导）

这是由向量的**点积（Dot Product）**推导出来的。决定一个空间平面只需要两样东西：
1. 平面上已知的一点 $P_0(x_0, y_0, z_0)$
2. 垂直于平面的一个法向量 $\mathbf{n} = \langle A, B, C \rangle$

假设平面上任意一点为 $P(x, y, z)$，那么向量 $\vec{P_0P} = \langle x-x_0, y-y_0, z-z_0 \rangle$ 一定在这个平面上。
因为法向量垂直于平面上的所有向量，所以法向量 $\mathbf{n}$ 和向量 $\vec{P_0P}$ 的点积必须为 $0$：
$$\mathbf{n} \cdot \vec{P_0P} = 0$$

展开点积：
$$\langle A, B, C \rangle \cdot \langle x-x_0, y-y_0, z-z_0 \rangle = 0$$
$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$
$$Ax + By + Cz - (Ax_0 + By_0 + Cz_0) = 0$$

把常数项 $(Ax_0 + By_0 + Cz_0)$ 移到等号右边并令其为 $D$：
$$Ax + By + Cz = D$$

由此可见，平面方程里 $x, y, z$ 的系数 $A, B, C$ 最初就是从法向量里来的。

---

## 3. 几何直觉：固定方向上的投影长度

如果将方程改写成位置向量的形式，不仅能解释法向量，还能解释常数 $D$ 的几何意义。
平面方程 $Ax + By + Cz = D$ 就是两个向量的**点积**：
$$\langle A, B, C \rangle \cdot \langle x, y, z \rangle = D$$
可以简写为：
$$\mathbf{n} \cdot \mathbf{r} = D$$
（其中 $\mathbf{r} = \langle x, y, z \rangle$ 是平面上任意一点的位置向量，即起点在原点，终点在平面上的向量）

根据点积的几何公式：$\mathbf{n} \cdot \mathbf{r} = |\mathbf{n}| \times |\mathbf{r}| \cos(\theta)$。
仔细看 $|\mathbf{r}| \cos(\theta)$ 这部分，这在几何上正好是**位置向量 $\mathbf{r}$ 在法向量 $\mathbf{n}$ 方向上的“投影长度”**！

> **大白话理解**：
> 平面上所有的点，无论它们在空间中怎么分布，只要把它们的位置向量（与原点的连线）**投影到法向量 $\mathbf{n}$ 的方向上**，投影的长度（乘上法向量的模长后）永远是一个**固定值** $D$。

---

## 4. 与原点距离的关系（归一化）

如果我们把法向量 $\mathbf{n}$ 变成**单位向量**（即长度为 1 的向量，记为 $\mathbf{u}$），即将等式两边同时除以法向量的长度 $|\mathbf{n}|$：
$$ \left( \frac{\mathbf{n}}{|\mathbf{n}|} \right) \cdot \mathbf{r} = \frac{D}{|\mathbf{n}|} $$
$$ \mathbf{u} \cdot \mathbf{r} = d $$

这个公式里的 **$d = \frac{D}{|\mathbf{n}|}$**，就是这个**“确定值”**的核心几何意义：
**它是坐标原点 $(0,0,0)$ 到这个平面的垂直最短距离。**

### 示例验证
对于平面 $x + y + z = 1$：
* 法向量 $\mathbf{n} = \langle 1, 1, 1 \rangle$
* 常数 $D = 1$
* 法向量的长度 $|\mathbf{n}| = \sqrt{1^2 + 1^2 + 1^2} = \sqrt{3}$

原点到这个平面的垂直距离就是： $d = \frac{1}{\sqrt{3}}$

**最终的几何直觉画面**：
空间中所有的点 $(x, y, z)$ 组成了一个平面 $x + y + z = 1$，如果你从原点向这些平面上的点画连线（位置向量），并将这些线全部投影到 $\langle 1, 1, 1 \rangle$ 这个固定的垂直方向上，它们的**投影长度永远固定等于 $\frac{1}{\sqrt{3}}$**（也就是原点到该平面的垂线长度）。
