# 平面的截距式方程 (Intercept Form of a Plane)

## 1. 核心公式与极简形式

平面的截距式方程可以说是平面方程中最著名且形式极度优美的一种。它完美契合了平面的一般方程（$Ax + By + Cz = D$），但形式更加直观。

设平面与三个坐标轴的交点（即截距，intercepts）分别为：
*   **$x$-intercept 为 $a$**：平面过点 $(a, 0, 0)$
*   **$y$-intercept 为 $b$**：平面过点 $(0, b, 0)$
*   **$z$-intercept 为 $c$**：平面过点 $(0, 0, c)$

*(前提条件是 $a, b, c \neq 0$，也就是该平面不经过原点)*

那么，该平面的方程可以直接写为：
$$ \frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1 $$

---

## 2. 详细推导过程（代数代入法）

我们可以用最基础的代数代入法，从一般方程推导出这个绝美的结果：

设平面的标准方程为：
$$Ax + By + Cz = D$$

1. **代入点 $(a, 0, 0)$**：
   $$A(a) + B(0) + C(0) = D \implies Aa = D \implies A = \frac{D}{a}$$
   
2. **代入点 $(0, b, 0)$**：
   $$A(0) + B(b) + C(0) = D \implies Bb = D \implies B = \frac{D}{b}$$
   
3. **代入点 $(0, 0, c)$**：
   $$A(0) + B(0) + C(c) = D \implies Cc = D \implies C = \frac{D}{c}$$

现在把求出来的 $A, B, C$ 代回到原方程中：
$$\left(\frac{D}{a}\right)x + \left(\frac{D}{b}\right)y + \left(\frac{D}{c}\right)z = D$$

因为已知平面不过原点，所以 $D \neq 0$。将等式两边同时除以 $D$，我们便得到了最终对称、优美的截距式方程：
**$$ \frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1 $$**

---

## 3. 几何直觉与法向量复习

我们可以用之前学过的 [[平面方程与法向量的几何直觉]] 来审视这个结果。

在平面的一般方程 $Ax + By + Cz = D$ 中，方程前面的系数 $(A, B, C)$ 直接构成了平面的法向量 $\mathbf{n}$。

因此，在截距式方程 $\frac{1}{a}x + \frac{1}{b}y + \frac{1}{c}z = 1$ 中，谁是法向量？
方程前面的系数就是法向量！所以，这个平面的**法向量** $\mathbf{n}$ 就是：
$$ \mathbf{n} = \langle \frac{1}{a}, \frac{1}{b}, \frac{1}{c} \rangle $$

### ⚡ 实战秒杀技巧
如果遇到题目说：*“平面在三个坐标轴上的截距分别是 2, 3, 4”*。
你不再需要去算繁琐的叉乘找法向量了，直接秒写答案：
$$ \frac{x}{2} + \frac{y}{3} + \frac{z}{4} = 1 $$
这就是数学形式美与几何直觉结合的最佳体现。
