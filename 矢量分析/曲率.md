# 曲率（Curvature）

> 曲率描述一条曲线在某一点处**弯曲的程度**。曲率越大，曲线在该点弯得越急。

---

## 一、定义

对于由向量函数 $\mathbf{r}(t)$ 描述的空间曲线，其**曲率** $\kappa(t)$ 定义为：

$$\boxed{\kappa(t) = \frac{|\mathbf{r}'(t) \times \mathbf{r}''(t)|}{|\mathbf{r}'(t)|^3}}$$

其中：
- $\mathbf{r}'(t)$：速度向量（切向量）
- $\mathbf{r}''(t)$：加速度向量
- $\times$：向量叉乘
- $|\cdot|$：向量的模长

曲率的倒数 $\rho = 1/\kappa$ 称为**曲率半径**。

---

## 二、详细推导

### 2.1 从定义出发

曲率最原始的定义是**单位切向量对弧长的变化率**：

$$\kappa = \left|\frac{d\mathbf{T}}{ds}\right|$$

其中：
- $\mathbf{T}$ 是单位切向量：$\displaystyle\mathbf{T} = \frac{\mathbf{r}'}{|\mathbf{r}'|}$
- $s$ 是弧长参数

### 2.2 链式法则展开

由于 $\mathbf{T}$ 是 $t$ 的函数，而 $t$ 又是 $s$ 的函数（通过 $ds/dt = |\mathbf{r}'|$）：

$$\frac{d\mathbf{T}}{ds} = \frac{d\mathbf{T}/dt}{ds/dt} = \frac{1}{|\mathbf{r}'|}\frac{d\mathbf{T}}{dt}$$

因此：

$$\kappa = \frac{1}{|\mathbf{r}'|}\left|\frac{d\mathbf{T}}{dt}\right|$$

### 2.3 计算 $d\mathbf{T}/dt$

设 $v = |\mathbf{r}'|$，则 $\mathbf{r}' = v\mathbf{T}$。

对 $\mathbf{T} = \mathbf{r}'/v$ 求导：

$$\frac{d\mathbf{T}}{dt} = \frac{\mathbf{r}''v - \mathbf{r}'v'}{v^2} = \frac{\mathbf{r}''v - \mathbf{r}'v'}{v^2}$$

### 2.4 关键的叉乘技巧

直接计算 $|d\mathbf{T}/dt|$ 比较繁琐。我们转而计算 $\mathbf{r}' \times \mathbf{r}''$：

$$\mathbf{r}' \times \mathbf{r}'' = (v\mathbf{T}) \times \left(v'\mathbf{T} + v\frac{d\mathbf{T}}{dt}\right)$$

展开叉乘：

$$\mathbf{r}' \times \mathbf{r}'' = v\mathbf{T} \times v'\mathbf{T} + v\mathbf{T} \times v\frac{d\mathbf{T}}{dt}$$

由于 $\mathbf{T} \times \mathbf{T} = \mathbf{0}$，第一项消失：

$$\mathbf{r}' \times \mathbf{r}'' = v^2 \left(\mathbf{T} \times \frac{d\mathbf{T}}{dt}\right)$$

### 2.5 利用单位向量的性质

因为 $\mathbf{T}$ 是单位向量（$|\mathbf{T}| = 1$），对其求导：

$$\mathbf{T} \cdot \mathbf{T} = 1 \quad\Rightarrow\quad 2\mathbf{T} \cdot \frac{d\mathbf{T}}{dt} = 0$$

这说明 $\displaystyle\frac{d\mathbf{T}}{dt}$ 与 $\mathbf{T}$ **垂直**。

对于两个垂直向量，叉乘的模等于模的乘积：

$$\left|\mathbf{T} \times \frac{d\mathbf{T}}{dt}\right| = |\mathbf{T}| \cdot \left|\frac{d\mathbf{T}}{dt}\right| = \left|\frac{d\mathbf{T}}{dt}\right|$$

因此：

$$|\mathbf{r}' \times \mathbf{r}''| = v^2 \left|\frac{d\mathbf{T}}{dt}\right| = |\mathbf{r}'|^2 \left|\frac{d\mathbf{T}}{dt}\right|$$

### 2.6 代回曲率定义

由 $\displaystyle\kappa = \frac{1}{|\mathbf{r}'|}\left|\frac{d\mathbf{T}}{dt}\right|$，得：

$$\left|\frac{d\mathbf{T}}{dt}\right| = \kappa |\mathbf{r}'|$$

代入上式：

$$|\mathbf{r}' \times \mathbf{r}''| = |\mathbf{r}'|^2 \cdot \kappa |\mathbf{r}'| = \kappa |\mathbf{r}'|^3$$

整理即得：

$$\boxed{\kappa = \frac{|\mathbf{r}' \times \mathbf{r}''|}{|\mathbf{r}'|^3}}$$

### 2.7 参数化无关性验证

如果进行参数变换 $t \to \tau$（设 $dt/d\tau = \lambda$）：

- $\mathbf{r}'_\tau = \lambda \mathbf{r}'_t$
- $\mathbf{r}''_\tau = \lambda^2 \mathbf{r}''_t + \lambda' \mathbf{r}'_t$

分子：$|\mathbf{r}'_\tau \times \mathbf{r}''_\tau| = |\lambda \mathbf{r}'_t \times (\lambda^2 \mathbf{r}''_t + \lambda' \mathbf{r}'_t)| = \lambda^3 |\mathbf{r}'_t \times \mathbf{r}''_t|$

分母：$|\mathbf{r}'_\tau|^3 = \lambda^3 |\mathbf{r}'_t|^3$

两者同比例缩放，**曲率是曲线本身的内禀性质**，与参数化方式无关。$\blacksquare$

## 三、几何意义

### 3.1 密切圆（Osculating Circle）

在曲线上每一点，都存在一个**最贴合曲线的圆**，称为密切圆。

- **曲率半径**：$\rho = 1/\kappa$，就是密切圆的半径
- **曲率中心**：密切圆的圆心，位于主法线方向上

> **直觉**：曲率越大 $\Rightarrow$ 曲率半径越小 $\Rightarrow$ 弯得越急 $\Rightarrow$ 密切圆越小。

### 3.2 方向变化的速率

曲率量的是**运动方向改变得有多快**，而非位置改变得有多快。

想象开车：
- 直道：方向不变，$\kappa = 0$
- 急弯：方向迅速改变，$\kappa$ 大
- 缓弯：方向缓慢改变，$\kappa$ 小

公式中的分母 $|\mathbf{r}'|^3$ 正是为了**消除速度大小的影响**——无论开多快，同一条弯道的"弯曲程度"是固定的。

### 3.3 叉乘的几何角色

分子 $|\mathbf{r}' \times \mathbf{r}''|$ 是速度向量和加速度向量张成的**平行四边形面积**。

由于叉乘只保留垂直分量，它实际上量的是：
> **加速度中垂直于速度方向的分量**（即导致转向的部分）

切向加速度（与速度平行）对叉乘无贡献，因此也不影响曲率——这完全符合几何直觉：加速或减速不改变运动方向，也就不改变曲率。

---

## 四、物理意义

### 4.1 加速度的分解

加速度总可以分解为：

$$\mathbf{a} = \mathbf{a}_\parallel + \mathbf{a}_\perp$$

| 分量 | 表达式 | 物理效应 |
|------|--------|----------|
| **切向** $\mathbf{a}_\parallel$ | $(\mathbf{a}\cdot\mathbf{T})\mathbf{T}$ | 改变**速率**（加速/减速） |
| **法向** $\mathbf{a}_\perp$ | $\mathbf{a} - \mathbf{a}_\parallel$ | 改变**方向**（转弯） |

曲率只与法向加速度有关。

### 4.2 曲率与法向加速度的关系

由圆周运动的向心加速度公式推广：

$$a_\perp = \kappa v^2 = \frac{v^2}{\rho}$$

这可以从原公式直接验证：

- $|\mathbf{r}' \times \mathbf{r}''| = v \cdot a_\perp$（因为叉乘只取垂直分量）
- 代入曲率公式：$\displaystyle\kappa = \frac{v \cdot a_\perp}{v^3} = \frac{a_\perp}{v^2}$

因此：

$$\boxed{a_\perp = \kappa v^2}$$

**物理直觉**：
- 速度加倍，同样的弯道需要四倍的法向加速度才能维持
- 曲率半径越小（弯越急），同样的速度需要越大的法向加速度

### 4.3 与牛顿第二定律的联系

维持曲线运动所需的**向心力**直接由曲率决定：

$$F_\perp = m a_\perp = m\kappa v^2 = \frac{mv^2}{\rho}$$

这就是经典力学中[[../经典力学/曲线坐标系加速度推导|曲线坐标系加速度]]的数学基础——弯曲的路径天然要求法向的约束力。

## 五、平面曲线的特例

对于平面曲线 $\mathbf{r}(t) = (x(t), y(t), 0)$，叉乘退化为 $z$ 方向标量：

$$\mathbf{r}' \times \mathbf{r}'' = (0, 0, x'y'' - x''y')$$

因此：

$$\boxed{\kappa = \frac{|x'y'' - x''y'|}{(x'^2 + y'^2)^{3/2}}}$$

### 函数图像 $y = f(x)$ 的特例

对于平面上的函数图像 $y = f(x)$，我们取 $x$ 作为参数，写出向量方程：

$$\mathbf{r}(x) = x\,\mathbf{i} + f(x)\,\mathbf{j}$$

对 $x$ 求一阶和二阶导：

$$\mathbf{r}'(x) = \mathbf{i} + f'(x)\,\mathbf{j}$$
$$\mathbf{r}''(x) = f''(x)\,\mathbf{j}$$

计算叉乘 $\mathbf{r}' \times \mathbf{r}''$。由于平面曲线在 $xy$ 平面内，叉乘只有 $z$ 分量：

$$\mathbf{r}' \times \mathbf{r}'' = (\mathbf{i} + f'(x)\,\mathbf{j}) \times (f''(x)\,\mathbf{j})$$

利用 $\mathbf{i} \times \mathbf{j} = \mathbf{k}$ 和 $\mathbf{j} \times \mathbf{j} = \mathbf{0}$：

$$\mathbf{r}' \times \mathbf{r}'' = f''(x)\,\mathbf{k}$$

因此：

$$|\mathbf{r}' \times \mathbf{r}''| = |f''(x)|$$

再计算速度大小：

$$|\mathbf{r}'(x)| = \sqrt{1 + [f'(x)]^2}$$

代入曲率公式 $\displaystyle\kappa = \frac{|\mathbf{r}' \times \mathbf{r}''|}{|\mathbf{r}'|^3}$：

$$\boxed{\kappa(x) = \frac{|f''(x)|}{\left[1 + (f'(x))^2\right]^{3/2}}}$$

这是微积分中最常见的曲率公式。其几何意义非常直观：
- **二阶导 $f''(x)$**：反映函数的"凹凸程度"，直接决定曲率大小
- **分母 $[1+(f')^2]^{3/2}$**：是斜率的修正因子。当曲线很陡（$|f'| \gg 1$）时，同样的 $f''$ 对应的实际曲率更小——因为曲线在"拉伸"后显得"更直"

---

### 直观理解：为什么要除以 $(1+f'^2)^{3/2}$？

#### 视角一：水平切线近似

当曲线在某点**水平**（$f' = 0$）时，公式简化为：

$$\kappa = |f''(x)|$$

此时函数局部近似于抛物线：

$$y \approx f(x_0) + \frac{1}{2}f''(x_0)(x-x_0)^2$$

这正是我们最直觉的"弯得有多急"——二阶导直接量化了偏离直线的速度。

#### 视角二：斜率的"拉伸效应"

当曲线变陡（$|f'|$ 增大），同样的 $f''$ 对应的**实际弯曲程度**被"稀释"了。

想象两个函数：
- $y_1 = x^2$ 在 $x=0$ 处：$f'=0,\; f''=2$，曲率 $\kappa = 2$
- $y_2 = 10x^2$ 在 $x=0$ 处：$f'=0,\; f''=20$，曲率 $\kappa = 20$（弯得更急）

但如果比较 $y = x^2$ 在 $x=10$ 处（$f'=20,\; f''=2$）：

$$\kappa = \frac{2}{(1+400)^{3/2}} \approx \frac{2}{8020} \approx 0.00025$$

非常小的曲率！虽然 $f''=2$ 不变，但曲线在那里几乎垂直，视觉上几乎是条直线。

> **一句话**：分母是"倾斜惩罚"——曲线越陡，同样的二阶导带来的"转弯感"越弱。

#### 视角三：弧长参数的视角（几何根源）

曲率本质上是**对弧长**的变化率，而非对参数 $x$ 的变化率。

弧长元素：

$$ds = \sqrt{1 + [f'(x)]^2}\, dx$$

当 $f'$ 很大时，$dx$ 对应的实际弧长 $ds$ 很大。用 $x$ 作为参数时，我们"跑"得很快（沿曲线），所以同样的方向变化显得"更慢"——曲率更小。分母中的 $(1+f'^2)^{3/2}$ 正是把"对 $x$ 的变化"正确转换为"对弧长的变化"所需的修正。

#### 视角四：平面运动的物理图像

对于平面参数曲线，分子 $|x'y'' - x''y'|$ 就是 $|\mathbf{r}' \times \mathbf{r}''| = v \cdot a_\perp$，即**速度 × 法向加速度**。

分母 $v^3$ 让它变成 $a_\perp / v^2$。这正是圆周运动中向心加速度的公式 $\displaystyle a_\perp = \frac{v^2}{R}$ 的逆用——曲率 $\kappa = 1/R = a_\perp / v^2$。

> 分子告诉你"为了转向花了多大力气"，分母把"跑得多快"的影响 normalize 掉。

## 六、例题

### 例 1：圆的曲率

设圆的参数方程：$\mathbf{r}(t) = (R\cos t,\; R\sin t,\; 0)$

- $\mathbf{r}' = (-R\sin t,\; R\cos t,\; 0)$，$|\mathbf{r}'| = R$
- $\mathbf{r}'' = (-R\cos t,\; -R\sin t,\; 0)$

叉乘：

$$\mathbf{r}' \times \mathbf{r}'' = (0,\; 0,\; R^2\sin^2 t + R^2\cos^2 t) = (0,\; 0,\; R^2)$$

$$|\mathbf{r}' \times \mathbf{r}''| = R^2$$

曲率：

$$\kappa = \frac{R^2}{R^3} = \frac{1}{R}$$

**结论**：圆的曲率处处相等，等于半径的倒数。曲率半径 $\rho = R$，恰好就是圆本身的半径——密切圆就是自己。

### 例 2：圆柱螺旋线

设螺旋线：$\mathbf{r}(t) = (a\cos t,\; a\sin t,\; bt)$

- $\mathbf{r}' = (-a\sin t,\; a\cos t,\; b)$，$|\mathbf{r}'| = \sqrt{a^2 + b^2}$
- $\mathbf{r}'' = (-a\cos t,\; -a\sin t,\; 0)$

叉乘：

$$\mathbf{r}' \times \mathbf{r}'' = (ab\sin t,\; -ab\cos t,\; a^2)$$

$$|\mathbf{r}' \times \mathbf{r}''| = \sqrt{a^2b^2 + a^4} = a\sqrt{a^2 + b^2}$$

曲率：

$$\kappa = \frac{a\sqrt{a^2 + b^2}}{(a^2 + b^2)^{3/2}} = \frac{a}{a^2 + b^2}$$

**物理直觉**：
- 当 $b = 0$（退化为圆）：$\kappa = 1/a$ ✓
- 当 $b \to \infty$（越来越"陡"）：$\kappa \to 0$，趋近于直线
- 螺距越大，曲线越"直"，曲率越小

## 七、总结

| 视角 | 核心结论 |
|------|----------|
| **定义** | 单位切向量对弧长的变化率 |
| **公式** | $\displaystyle\kappa = \frac{\vert\mathbf{r}' \times \mathbf{r}''\vert}{\vert\mathbf{r}'\vert^3}$ |
| **几何** | 密切圆半径的倒数；方向变化的固有几何速率 |
| **物理** | $\displaystyle a_\perp = \kappa v^2 = \frac{v^2}{\rho}$，法向加速度决定曲率 |
| **参数化** | 与参数选择无关，是曲线的内禀性质 |

## 进阶：空间曲线的完整描述

曲率只描述了曲线"弯得多急"。要完整描述一条空间曲线，还需要：

- **[[弗雷内标架]]** — 沿曲线运动的局部正交标架 $(\mathbf{T}, \mathbf{N}, \mathbf{B})$
- **[[挠率]]** — 曲线"扭出"密切平面的程度

曲率 $\kappa$ 与挠率 $\tau$ 共同构成了空间曲线的**完备内禀描述**。详见空间曲线的[[挠率#基本定理|基本定理]]。
