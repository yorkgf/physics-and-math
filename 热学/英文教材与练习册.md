# 英文教材与练习册（热学）

> **结论**：主教材选 **Daniel V. Schroeder《An Introduction to Thermal Physics》**（Oxford，初版 2000 至今唯一版次、多次重印）；练习先用**作者官网免费的按节推荐习题**，进阶再上 Landsberg（Dover）刷题。全部资料均有合法免费渠道（见文末）。
> 信息核实日期：2026-11-19（Open Library / archive.org / 作者官网）

---

## 一、为什么是 Schröeder

| 维度 | 说明 |
| --- | --- |
| **覆盖匹配** | 课程 9 章它覆盖约 90%（含第 5 章输运、第 9 章相变），唯一缺口是第 8 章液体表面性质 |
| **风格** | 从具体例子出发、推导细、直觉强；Physics Today 与 AJP 均有好评（官网有链接） |
| **习题体系** | 章末题量大且分层；官网有**按 section 的 Recommended Problems**，作者明说「给 first-time instructors 和 **self-study** 的读者」 |
| **附带资源** | 官网含 Full Contents / Excerpts（试读 PDF）/ Important equations（公式速查）/ Corrections / Clarifications & FAQs / Course plans（他人排课方案）/ Figures & Tables |
| **作者课程资料** | 作者在 Weber State 的 Physics 3180「Thermal Physics」课程页：syllabus、**14 周推荐习题 PDF**、schedule、词汇表（考前默词用） |
| **数学后盾** | Appendix A 量子力学速成 + Appendix B 数学结果（高斯积分 / 伽马函数 / 斯特林近似）——正好支撑课程第 4 章量子气体 |
| **版本** | 初版 2000（Addison-Wesley），现由 OUP 出版，**仅此一版**，不存在「买旧版会过时」问题 |

**ISBN**（作者官网链至 OUP）：平装 `978-0192895554` · 精装 `978-0192895547`

## 二、书 ↔ 课程周计划对照

> ⚠️ 注意该书特色：它**第 2 章就用统计方法建立熵**，比课程（第 7 章才出现熵）早得多。按下表读相当于「提前预习熵」，对课程第 7 章是巨大铺垫，放心按表走。

| 周 | 课程内容（分 P） | Schröeder 章节 |
| --- | --- | --- |
| W1–W2 | 温度 / 平衡态 / 状态方程（P1–12） | Ch1 1.1–1.3（热平衡、理想气体、均分）+ 1.4–1.5 |
| W3 | 理想气体微观图像 + 无序系统（P13–19） | 1.2 Microscopic Model + 2.1–2.2（两态系统 / Einstein 固体） |
| W4 | 概率论简介（P20–24） | 2.4 大数与**斯特林近似** + App B.3 |
| W5 | 麦克斯韦分布律（P25–28） | **6.4 The Maxwell Speed Distribution** |
| W6–W7 | 最概然分布 / 能量均分（P29–39） | 2.2–2.6（Einstein 固体、熵的统计式）+ 6.1–6.3（Boltzmann 因子 / 配分函数 / 均分定理） |
| W8 | 量子气体简介（P40–44） | Ch7 7.1–7.3（Gibbs 因子、玻色/费米、费米气）+ 7.6（BEC） |
| W9 | 碰撞与输运（P45–55） | ⭐ **1.7 Rates of Processes**（热传导 / 黏度 / 扩散）——正好一整节 |
| W10–W11 | 热一律 / 循环 / 卡诺（P56–71） | 1.4–1.6 + Ch4 4.1–4.4（热机 / 制冷机 / 卡诺循环） |
| W12–W13 | 热二律 / 熵（P72–85） | 2.6 + 3.1–3.4（熵与热、力学平衡、热力学恒等式） |
| W14 | 热力学函数 / 第三定律（P86–92） | 5.1–5.2（自由能）+ 3.5（化学势）；第三定律见 4.4「Toward Absolute Zero」 |
| W15 | 液体彻体 / 表面性质（P93–100） | ⚠️ **缺口**：以视频 + 笔记为主；表面张力可查 Zemansky（见下） |
| W16 | 相变与相平衡（P101–111） | 5.3（相变 / 克劳修斯–克拉珀龙 / van der Waals）+ 5.4（混合物相变） |

> 排课参考：作者官网 Course plans 页明确给出「一学期怎么取舍」「章节依赖图」——自学节奏可完全照抄他的 Weber State 方案。

## 四、练习资源阶梯（按顺序用）

> 若改用 MIT 5.60 为主线视频（见 6.3），把第 1–2 级换成「5.60 习题 + Atkins」，Schroeder 降级为统计力学 / 动理论补充。

1. **作者官网 Recommended Problems**（physics.weber.edu/thermal/recprobs.html）
   按 section 选题（如 1.5 节做 1.32、1.34、1.36、1.38），明为 self-study 而列。**起步就用这个，不要盲刷章末全部题。**
2. **章末题其余部分** + 官网 Important equations 作公式速查；课程页 14 周习题 PDF 可作额外量。
3. **Landsberg《Problems in Thermodynamics and Statistical Physics》**（Dover，1971 初版 / 廉价再版）——经典纯题目+解答 drill book，适合周末集中刷。
4. **Lim (ed.)《Problems and Solutions on Thermodynamics and Statistical Mechanics》**（World Scientific，1990；2022 有扩充新版）——源自中国高校研究生入学试题，题难解全；基础扎实后再上。
5. **我每周按视频内容出 3–5 道概念/计算题**（既有工作流，见 [[学习进度/热学#✍️ 练习 / 作业进度]]）。

> 自律提示：archive.org 可借到 Instructor's Solutions Manual（教师版解答）。**先做后对**，否则就是假进度。

## 六、附：英文视频课（MIT 5.60）与本书的匹配

> **两种用法，二选一**：
> - **补丁式**（默认）：中文课（北大）为主线，5.60 只补三块 —— ① 化学热力学（补本书第 5 章偏薄处）② 反应动力学（本书与北大课均没有的拓展）③ 英文习题源。用法见 6.2。
> - **主线式**（更偏爱 5.60 讲法时）：以 5.60 的热力学部分为主线视频，**练习册配置见 6.3**；此时 Schroeder 降级为「统计力学 / 动理论」补充教材，北大视频降级为查漏对照。

### 6.1 为什么中文课仍是主线

| 维度 | 北大 欧阳颀《热学》（中文 · 111 讲 · 22 h 51 m） | MIT 5.60 Thermodynamics & Kinetics（英文） |
| --- | --- | --- |
| **语言成本** | 0 | 高：每讲约 50 min 连续英文讲授 + 术语 |
| **与本书匹配度** | ⭐⭐⭐⭐ 已有逐周对照表（见上文第二节） | ⭐⭐⭐ 化学热力学部分匹配好；统计力学部分比本书浅、且出现得晚 |
| **统计 / 动理论深度** | **深**：最概然分布（拉格朗日乘子法）、麦克斯韦分布、三种输运系数 | 浅：Boltzmann 分布与气体动理论各约 2–3 讲 |
| **热一律 / 热二律讲法** | 物理系路线（微观先行、先动理论后两定律） | 化学系路线（宏观先行，重焓 / 吉布斯自由能 / 平衡判据） |
| **独有内容** | 第 8 章液体彻体 / 表面性质讲全、第三定律、非平衡统计新进展 | **化学势的应用**：溶液 / 依数性 / 化学平衡；**反应动力学全套**（速率方程、Arrhenius、过渡态、催化） |
| **自学配套材料** | 只有视频 | **OCW 全套**：讲义 + 习题（含解答）+ 往年考卷，免费 |
| **节奏** | 单讲 5–20 min，日拱一卒 | 单讲约 50 min，只能周末整块 |
| **附加收益** | 中文学术术语 | 英文学术术语，直接服务本书英文习题 |

**结构性原因**：5.60 是 MIT 面向化学 / 化工的低年级「热力学 + 动力学」课，约七成内容与「北大课 + 本书」重叠。它独有的两块——化学热力学（溶液、化学平衡）与化学反应动力学——本书和北大课都没有；而北大课讲得远比 5.60 深的两块（最概然分布的严格推导、输运现象三系数）恰好是本书 1.7 节与第 2 章的重点。**所以替代是净亏损，当补丁是净收益。**

**另一层**：「教材是英文」不等于「视频也要英文」——语言成本是实打实的（50 min 英文讲授 ≈ 中文课 2–3 倍的认知负荷），而「与本书匹配」这个问题已经由上方的逐周对照表解决了，不需要靠视频语言来解决。

> ⚠️ **符号约定坑**：化学系（5.60）常用 ΔU = q + w（w 为外界对系统做功），中文物理教材常用 Q = ΔU + A（A 为系统对外做功）。Schroeder 的约定见本书 1.5–1.6 节——跨看时**先对齐符号**，否则一错连着一错。

> 📌 **素材入口**：MIT OCW 搜 "5.60 Thermodynamics and Kinetics"（有多个学期版本，讲义 / 习题 / 考卷齐全）；B 站 BV1Rt411i7tr 是其中某一学期的讲课录像（英文原声）。**只按上表挑块看，不必整课收藏。**

### 6.3 若以 5.60 为主线：练习册配置

> **总原则：跟着谁的记号走，就用谁的题。** 5.60 是化学系约定（ΔU = q + w，w 为外界对系统做功），Schroeder 与中文物理教材是物理系约定（Q = ΔU + A，A 为系统对外做功）——两套题**不要混在同一次练习里**，否则符号会连错一串。

| 层级 | 题源 | 为什么适合 5.60 | 获取 |
| --- | --- | --- | --- |
| **1** | **5.60 自己的 Problem Sets + Past Exams**（OCW） | 范围 / 深度 / 记号与视频零摩擦；MIT 题分 routine 与 challenge 两层，答案全 | 免费，OCW 直接下载 |
| **2** | **Atkins《Physical Chemistry》热力学篇**（de Paula & Atkins） | 目录几乎就是 5.60 大纲：第一定律 / 第二定律 / 纯物质相变 / 简单混合物 / 相图 / 化学平衡 / 电化学。章末 **Exercises**（短题，书末有 selected answers）+ **Problems**（大题，配 Solutions Manual 可自批） | archive.org 借旧版（8th–10th 即够，与 5.60 更贴近）或购新版；Solutions Manual 亦有旧版 |
| **3** | **Lim《Problems and Solutions on Thermodynamics and Statistical Mechanics》** | 题量足、**解答全**，补 Atkins「只给部分答案」的短板；偏物理系记号，适合月末集中刷 | 见第四节阶梯 |
| **4** | **Schroeder**（降级保留，别扔） | 5.60 的统计力学只给结论；Boltzmann 分布 / 配分函数 / 麦克斯韦分布 / 均分仍以 Schroeder + 官网 recprobs 最细 | 已借 |
| 备选主教材 | **McQuarrie & Simon《Physical Chemistry: A Molecular Approach》** | 嫌 Atkins 题太「套公式」时换它；讲解更重图像，统计力学篇比 Atkins 深、与 Schroeder 衔接更顺 | archive.org / 购买 |

**每周节奏**：看完 2–3 讲 → 做 5.60 当周 Problem Set（或 Atkins 对应章 Exercises 挑 5–8 题，核对书末答案）；每章收尾 → Atkins Problems 挑 3–5 题，配 Solutions Manual 自批；月末 → 一套 5.60 往年考卷。

**不建议**：Blundell / Baierlein / Kittel 的题（物理系记号、宏观 / 微观配比与 5.60 不合，做了是反向干扰）；秦允豪《热学》题可作「自检是否真懂」的对照，但不作主线。

> 💡 旁证：5.60 的 OCW「Readings」栏通常就指定 Atkins 或 McQuarrie 的对应章节（以你看到的学期页面为准）——这正是 Atkins 与它最配套的原因。
