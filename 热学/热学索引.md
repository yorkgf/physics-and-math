# 热学索引

> **课程**：[【热学 北京大学 欧阳颀院士】](https://www.bilibili.com/video/BV1vx411d78s/?share_source=copy_web&vd_source=ef759c3adcb25a9714afaab33e17e6e3)（B站 · **111 讲 · 22 h 51 m**，2026-11-19 经 B站 API 逐 P 核实）
> **进度追踪**：[[学习进度/热学]]（16 周计划 + 分讲打卡表）
> **教材**：[[英文教材与练习册]] — 主教材 Schröeder + 书↔周计划对照 + 练习阶梯 + 免费借阅渠道

## 📖 学习路径

1. **W1–W3**（P1–19）：第 1–2 章 —— 宏观框架 + 微观图像，建立「两套语言」
2. **W4–W8**（P20–44）：第 3–4 章 —— 动理论核心，概率论密集；W4 凭基础倍速过
3. **W9**（P45–55）：第 5 章 —— 输运现象
4. **W10–W14**（P56–92）：第 6–7 章 —— 热力学两定律 + 熵
5. **W15–W16**（P93–111）：第 8–9 章 —— 液体 + 相变
