### 实验步骤详解

#### 第一阶段：环境访问（5分钟）

**教师演示：**
1. 打开浏览器，访问 `http://192.168.0.169`
2. 展示DVWA登录页面
3. 使用默认账户登录：`admin` / `password`

**学生操作：**
- 跟随教师步骤完成登录
- 遇到问题及时举手示意

**常见问题：**
- Q: 无法访问网站？
  A: 检查网络连接，确认IP地址正确，尝试清除浏览器缓存

#### 第二阶段：界面熟悉（10分钟）

**教师引导：**
1. 介绍DVWA主界面布局
2. 展示左侧导航菜单
3. 说明各功能模块的作用

**关键模块说明：**

| 模块名称 | 功能说明 | 对应攻击类型 |
|---------|---------|-------------|
| Brute Force | 暴力破解测试 | 密码攻击 |
| SQL Injection | SQL注入测试 | 注入攻击 |
| XSS (Reflected) | 反射型XSS | 跨站脚本 |
| XSS (Stored) | 存储型XSS | 跨站脚本 |
| CSRF | 跨站请求伪造 | 会话攻击 |
| File Upload | 文件上传测试 | 文件漏洞 |
| Command Injection | 命令注入测试 | 系统命令执行 |
| File Inclusion | 文件包含测试 | 文件包含漏洞 |

**学生任务：**
- 浏览所有功能模块
- 记录每个模块的名称和位置

#### 第三阶段：安全级别配置（10分钟）

**教师讲解：**
1. 导航到 DVWA Security 页面
2. 解释四个安全级别的含义
3. 演示如何切换安全级别

**安全级别说明：**

| 级别 | 特点 | 适用场景 |
|-----|------|---------|
| Low | 无任何防护 | 学习攻击原理 |
| Medium | 基础防护 | 理解简单防御 |
| High | 较强防护 | 学习绕过技术 |
| Impossible | 完整防护 | 学习最佳实践 |

**学生操作：**
1. 将安全级别设置为 **Low**
2. 点击 **Create/Reset Database** 初始化数据库
3. 观察页面变化

#### 第四阶段：记录与分析（5分钟）

**学生任务：**
1. 记录每个安全级别的配置差异
2. 分析安全级别提升时增加了哪些防护措施
3. 完成实验记录表格

---

### 预期答案

#### 安全级别配置差异表

| 安全特性 | Low | Medium | High | Impossible |
|---------|-----|--------|------|-----------|
| 输入验证 | 无 | 基础 | 严格 | 完整 |
| 错误处理 | 详细错误信息 | 部分隐藏 | 隐藏 | 自定义错误页 |
| 会话管理 | 无超时 | 基础超时 | 严格超时 | 完整会话管理 |
| CSRF防护 | 无 | 无 | Token | Token+验证 |

#### 思考问题参考答案

1. **为什么DVWA要设置不同的安全级别？**
   - 让学生逐步理解攻击和防御的关系
   - 从简单到复杂，循序渐进学习
   - 模拟真实环境中安全配置的演进过程

2. **安全级别配置体现了哪些安全控制类型？**
   - 技术控制：输入验证、错误处理、会话管理
   - 管理控制：安全策略、配置标准

3. **在真实环境中，如何确定系统的适当安全级别？**
   - 评估资产价值和敏感度
   - 分析潜在威胁和风险
   - 考虑业务需求和成本效益
   - 遵循合规要求

### 常见问题与解答

| 问题 | 解答 |
|-----|------|
| 忘记DVWA登录密码 | 默认账户：admin/password，或重置数据库 |
| 页面显示错误 | 尝试清除浏览器缓存或更换浏览器 |
| 无法切换安全级别 | 确认已登录管理员账户 |
| 数据库初始化失败 | 检查MySQL服务是否运行 |
