### 实验步骤详解

#### 第一阶段：理解暴力破解（5分钟）

**教师讲解：**
1. 定义暴力破解攻击
2. 解释攻击原理
3. 展示攻击流程图

**攻击类型说明：**

| 类型 | 描述 | 示例 |
|-----|------|-----|
| 字典攻击 | 使用常见密码列表 | password, 123456 |
| 暴力穷举 | 尝试所有组合 | a, b, c...aa, ab... |
| 凭据填充 | 使用泄露的密码 | 从其他网站泄露的密码 |

**学生记录：**
- 记录三种攻击类型的特点

---

#### 第二阶段：Low安全级别攻击（10分钟）

**教师演示：**
1. 进入 Brute Force 模块
2. 输入用户名：`admin`
3. 输入密码：`123456`
4. 观察错误信息

**学生操作：**
1. 尝试以下用户名密码组合：

| 用户名 | 密码 | 结果 |
|-------|------|------|
| admin | password | |
| admin | admin | |
| admin | 123456 | |
| admin | qwerty | |
| admin | letmein | |

2. 记录每次尝试的结果

**关键观察点：**
- 错误信息是否泄露用户名是否存在
- 错误信息是否区分用户名错误和密码错误
- 是否有登录尝试限制

---

#### 第三阶段：分析认证漏洞（10分钟）

**教师引导：**
1. 分析DVWA的错误信息
2. 讨论信息泄露的风险
3. 引导学生思考防御措施

**错误信息分析：**

| 错误信息 | 泄露的信息 | 风险 |
|---------|-----------|------|
| "Username incorrect" | 用户名不存在 | 攻击者可枚举用户名 |
| "Password incorrect" | 用户名存在 | 攻击者确认用户名有效 |
| "Login failed" | 无 | 不泄露信息 |

**学生任务：**
1. 记录DVWA的错误信息
2. 分析泄露了什么信息
3. 提出改进建议

---

#### 第四阶段：设计强密码策略（5分钟）

**教师讲解：**
1. 强密码的特征
2. 密码策略的要素
3. 多因素认证的概念

**强密码要素：**

| 要素 | 要求 | 示例 |
|-----|------|-----|
| 长度 | 至少12字符 | `MyP@ssw0rd123` |
| 复杂度 | 包含大小写、数字、特殊字符 | `P@ssw0rd!` |
| 唯一性 | 不同网站使用不同密码 | 使用密码管理器 |
| 随机性 | 避免个人信息 | 不使用生日、姓名 |

**多因素认证（MFA）：**

| 因素类型 | 描述 | 示例 |
|---------|------|-----|
| 知识因素 | 你知道的 | 密码、PIN |
| 持有因素 | 你拥有的 | 手机、令牌 |
| 生物因素 | 你本身的 | 指纹、面部 |

### 预期答案

#### 错误信息分析参考答案

**DVWA Low级别的错误信息：**
- 用户名错误：`"Username and/or password incorrect."`
- 密码错误：`"Username and/or password incorrect."`

**分析：**
- 错误信息没有区分用户名和密码错误
- 这是一个较好的实践，不会泄露用户名是否存在
- 但Low级别没有登录尝试限制，仍存在风险

#### 强密码策略参考答案

**完整的密码策略应包含：**
1. 最小长度要求（至少12字符）
2. 复杂度要求（大小写+数字+特殊字符）
3. 密码历史记录（禁止重复使用最近5个密码）
4. 最长使用期限（90天强制更换）
5. 账户锁定策略（5次失败后锁定15分钟）

### 常见问题与解答

| 问题 | 解答 |
|-----|------|
| 暴力破解需要多长时间？ | 取决于密码复杂度和防护措施 |
| 为什么不用简单密码？ | 简单密码容易被破解 |
| 密码管理器安全吗？ | 比重复使用密码更安全 |
| MFA能完全防止攻击吗？ | 不能，但大大增加攻击难度 |
