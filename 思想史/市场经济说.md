# 市场经济说

**市场经济说**是解释[[现代性]]起源的一种传统范式。它认为，现代社会最早起源于西方，是因为西方率先发展出了资本主义市场经济制度。市场打破了封建的人身依附关系，将劳动力、土地和货币商品化，从而释放出前所未有的生产力。

## 主要代表

- **亚当·斯密**：分工和市场"看不见的手"带来财富增长；
- **马克思**：现代性就是资产阶级社会，资本主义生产方式是历史进步的引擎；
- **各类现代化理论**：将市场化、私有化和自由贸易视为现代化的核心路径。

## 核心逻辑

1. 市场经济打破了传统社会的等级束缚；
2. 利润动机刺激了技术创新和效率提升；
3. 资本积累推动了工业革命；
4. 因此，市场经济是现代性的发源地。

## 局限与批判

在[[现代性社会为什么最早起源于西方]]的讨论中，市场经济说受到多方面的质疑：

### 1. 因果倒置
市场经济本身就是现代性的一部分，用它来解释现代性的起源属于**循环论证**。它将现代性的**结果**误当作**原因**。

### 2. 历史反例
许多前现代文明（如中国宋代、伊斯兰世界、意大利城邦）都曾拥有高度发达的市场经济和商业文化，但它们并未自发进入现代社会。这说明市场经济本身并不必然导致现代性。

### 3. 博兰尼的批判
[[博兰尼]]在《大转型》中指出：
- 古代市场始终"嵌入"在社会伦理之中；
- **市场社会**（market society）——即市场支配整个社会——是19世纪的产物，而非现代性的原因；
- 因此，不能将"市场"与"现代性"混为一谈。

### 4. 无法解释价值革命
市场经济说无法回答：为什么西方文明会将"无止境地积累财富"视为道德义务？为什么"无限增长"成为社会的最高目标？这些问题必须诉诸[[韦伯典范]]和[[价值系统]]的分析。

## 在知识图谱中的位置

市场经济说处于解释链条的**表层**。它为理解现代性的经济结构提供了重要视角，但无法独立解释现代性的起源。在知识图谱中，它通常与以下节点相连：
- [[现代性社会为什么最早起源于西方]]（作为被批判的对象）
- [[博兰尼]]和[[市场社会]]（批判者）
- [[马克思典范]]（理论上的近亲）
- [[韦伯典范]]（提供更深层的替代解释）
