# 博兰尼

**卡尔·博兰尼**（Karl Polanyi，1886–1964）是匈牙利经济史学家、经济人类学家。他在《大转型：我们时代的政治与经济起源》（*The Great Transformation*，1944）中提出了对古典经济学和[[市场经济说]]的深刻批判。

## 核心思想

### 1. 嵌入（Embeddedness）
在前现代社会中，经济从来不是独立的领域，而是"嵌入"在社会关系、宗教伦理和政治制度之中的。贸易、交换和生产始终服从于社会的道德规范。

### 2. 市场社会（Market Society）
博兰尼区分了"市场"（market）和"市场社会"（market society）：
- **市场**古已有之，几乎所有文明都有局部市场的存在；
- **市场社会**则是19世纪的独特产物——意味着市场原则（供求关系、利润最大化）开始支配整个社会，市场从社会中"脱嵌"（disembedding）出来。

### 3. 虚拟商品（Fictitious Commodities）
土地、劳动力和货币本质上不是商品，却被资本主义市场经济假装为商品。这种"虚构"是社会危机（如大萧条、法西斯主义兴起）的根源。

### 4. 双重运动（Double Movement）
市场社会的扩张必然引发社会的自我保护运动（如劳工运动、福利国家、保护主义），形成"市场扩张"与"社会保护"之间的张力。

## 对"现代性起源"讨论的意义

博兰尼的理论实际上否定了"市场经济自发产生现代性"的古典叙事。他指出：
- 现代[[市场社会]]不是自然演化的结果，而是国家强力干预和社会建构的产物；
- 因此，用"市场经济"来解释现代性的起源，犯了将结果当作原因的错误。

这一理论为从[[市场经济说]]转向[[韦伯典范]]（即重视[[价值系统]]和观念变革）扫清了道路。
