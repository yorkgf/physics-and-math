# 现代性

**现代性**（Modernity）是指一种以理性化、世俗化、个体化和无限制增长为特征的社会形态与文明状态。它不仅仅是时间上的"现代"，更是一套独特的社会组织原则和价值系统。

## 核心特征

1. **理性化**（Rationalization）
   马克斯·韦伯指出，现代性的核心是世界的"祛魅"（disenchantment）和各个生活领域的理性化——经济理性化、法律理性化、行政理性化、科学理性化。

2. **科技与经济的无限制增长**
   与传统社会的"循环时间观"不同，现代社会建立在"进步"和"无限增长"的信念之上。这是[[现代性社会为什么最早起源于西方]]讨论中的关键定义。

3. **个体化**
   个人从传统的宗族、宗教和社区纽带中解放出来，成为权利和义务的独立承担者。

4. **市场脱嵌**
   按照[[博兰尼]]的观点，现代社会意味着[[市场社会]]的形成——市场从"嵌入"社会伦理转变为支配社会运行。
